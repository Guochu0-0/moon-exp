# 伪标签怎么打、怎么用：RoMa 自训练的方法候选（#126）

> 问题：在固定的特征侧配方上（DINOv2 每块注意力的 qkv 加秩 8 的 LoRA，α 16，LoRA 学习率 1e-4，其余同此前最好的配方；Val 后段均值约 0.322），伪标签这一侧还有哪些值得试的做法？本文给出三样东西：候选清单、旧做法重审、2–3 条方法故事线，供第四批实验（#127）选用。
>
> 约束：推理不能变慢；不能用 Val / Test 的影像训练；不扩充训练数据；**不改单个仿射怎么拟合**（仍是每对按 certainty 抽 1 万个匹配、3 px RANSAC 拟合一个全局仿射）。
>
> 标注约定：**【原文】** 指从论文正文读到的内容（arXiv PDF 转文本后阅读），给出节号或表号；**【推断】** 指本文的判断，没有实验验证；**自拟** 指找不到出处、由本文提出的做法或组合。调研日期 2026-10-09。
>
> 编号 P1、P2……与上两份调研的 R1–R15（[面向 RoMa 的无标注训练候选](https://github.com/Guochu0-0/moon-exp/blob/research/roma-unsupervised/docs/research/roma-unsupervised/README.md)）、C1–C13（[离线伪标签与迭代自训练](https://github.com/Guochu0-0/moon-exp/blob/research/offline-pseudo-label/docs/research/offline-pseudo-label/README.md)）不重号。已在那两份里出现、但从没试过的条目（C3 稳定性筛选、C4 课程式、R6 的方差头），这里改写到新配方上，并注明对应关系。

几个反复出现的词，先在这里解释：

- **certainty**：RoMa 对每个像素额外输出的一个分数，表示「这个像素给出的对应位置可不可信」。推理时按它抽 1 万个匹配再做 RANSAC，所以它直接决定哪些点进入最终的仿射估计。现在训练时它只被监督为「目标点是否落在另一张图的重叠区内」。
- **粗层分类**：RoMa 最粗的一层把对应位置当作在 64×64 个格点（锚点）中选一个的分类问题；各细层再在此基础上回归一个小位移（细化）。
- **打标**：离线跑一遍老师模型，得到每对的伪仿射以及选哪些对、哪些像素可信。**用标**：训练时这些标签怎样进入损失。
- **记忆（memorization）**：带噪标签学习里的说法。网络先学到干净标签共有的规律（早学阶段），之后才开始逐个背下错误的标签。

## 一、候选清单（只按成本排序）

成本单位：「1×」= 一次参照配方的训练（8000 步，batch 1；在 V100 上约 0.54 s/步，约 1.2 小时）。「一次打标推理」= 用某个模型把 Train 全部候选对按评测口径（560 → 864）过一遍，相当于现在生成伪标签的那一步。所有候选都只改训练端或离线打标，**推理时网络结构和计算量不变**；P5 多出的输出通道只在训练时使用，导出权重时删掉即可。

### 各条的补充说明

**P1。** 旧配方上「前 50% vs 全部」打平，所以只做硬切分预期不高。软加权的区别是：差的对仍然参与，但贡献按质量缩小；DAFormer 中这一权重是「置信度超过门槛的像素比例」【原文，式 (3)–(4)】。【推断】放开 DINOv2 后学生更能背下坏标签（见第二节开头），坏对的代价可能比旧配方上大。

**P2、P3。** STLD 针对的是回归任务里的伪标签：坐标回归不给置信度、门槛难定，作者改为由粗到细地使用伪标签【原文，摘要与 §IV】。在本任务中【推断】，每对一个全局仿射在大范围内大致对，在亚像素到几个像素的尺度上不一定对（地形起伏、SAR 的成像几何）；最细几层的回归正是把这些小误差当真值来学的地方。P2 给细层回归一个「误差够小就算对」的容差，P3 让细层晚一点才开始学。两者都不改粗层。

**P4。** 和已试过的 SAR 擦除不同：擦除时被遮处不监督位置、certainty 目标设为 0，教的是「看不见就别相信」；P4 被遮处**仍然监督**，教的是「看不见也要从周围推断出来」【原文：MIC 摘要与 §3】。MIC 的老师看完整图像，学生看遮挡图像；这里伪仿射本来就是在完整图像上得到的，所以不需要在线老师。【推断】月面大片弱纹理的区域（月海平原、阴影）在本地本来就「看不清」，P4 迫使网络更多依赖上下文，方向与这一困难一致。

**P5。** 原调研的 R6 有两个变体：(a) 去掉残差最大的像素，已试，持平；(b) 训练时用的方差头，**没有试过**。P5 是 (b) 的具体化，选型依据：SEA-RAFT 指出混合拉普拉斯让模型「不必死拟合含糊像素」，比单一 L1 和混合高斯都好【原文，§3.2、表 4】；β-NLL 指出普通的高斯负对数似然会让一开始拟合差的点权重越来越小、训练早早停住，用 β = 0.5 缓和【原文，摘要】。RoMa v2 只在残差 < 8 px 的像素上训练精度头，并且把残差从计算图里分离出来以求稳定【原文，§3 式 (4) 后】，可照搬。注意：RoMa 的 certainty 头已经存在，P5 加的是另一个量（误差有多大），不是替代 certainty。

**P6、P7、P8。** 这三条都来自带噪标签学习里的「早学–记忆」现象：网络先拟合干净样本，之后才背下错误标签；ELR 在线性模型里证明了这一点【原文，§3】。三者做法不同：P6 把标签本身逐步换成模型早期的一致预测（Self-Adaptive Training 的滑动平均修正，作者报告去掉滑动平均后性能明显下降【原文，表 2a】）；P7 不改标签，加一项正则把预测拉向时间平均，ELR 附录 D 指出只做时间平均、不加这一正则，目标最终仍会拟合噪声【原文，图 D.1】；P8 不改目标，只按预测是否稳定降权。P6 和已试过的稠密自标签不同：那里是用一个**固定的、训完的老师**的稠密输出替换部分目标；P6 的目标来自**当前学生自己的历史平均**，并从伪仿射出发逐步过渡。存储：每对存一张 64×64×2 的位移图即可（粗层分辨率），约 8000 对时不到 1 GB。

**P9。** 解决 certainty 只学到「是否在重叠区」的问题。现在重叠区内每个像素都被要求高 certainty，包括本来无法匹配的像素（阴影、无纹理、SAR 叠掩处）；推理时按 certainty 抽点，这些像素会混进 RANSAC。【推断】改为「可匹配」目标后，推理抽到的 1 万个点会更集中在真正可匹配的地方，这是一个不增加推理开销、却作用在最终仿射估计上的通道。往返一致筛选在光流、点跟踪的自训练中有效【原文：2401.00850 摘要与 §III】；该文也指出门槛过严只剩容易的点、过松又放进噪声，需要扫一个中间值【原文，§III 门槛讨论】。

**P10–P12。** 打标侧的「组合多次打标结果」。P10 本身只产生可信度，不改仿射的拟合方式；最终标签取 K 个仿射的中位数属于「组合多次结果」，若要严格不动标签可只用离散度。P11、P12 是 P10 产出的两种用法。P12 的关键在于「老师和学生比较」：Unbiased Teacher v2 发现只看老师自己的置信度不能防止误导性的回归标签，在最严的定位指标上甚至变差【原文，§4 消融】。在本任务中「老师」是离线的伪仿射，它的不确定度来自 P10，学生的不确定度来自 P5。

**P13。** 原文中两个网络「学习能力不同，能滤掉不同类型的错误」【原文，§1】；本任务两个学生同结构同起点，只靠种子和数据顺序制造差异，差异可能不足【推断】。成本翻倍，放在末档。

**P14。** 旧配方上换老师、迭代都持平；理由和新配方下的变化见第二节。这里加上「按稳定性由少到多」的课程，才和旧实验不同。

## 二、旧做法重审：放开 DINOv2 之后值不值得在新配方上重试

**判断依据。** 第三批实验中，DINOv2 放开得越多（更高 LoRA 学习率、更大秩、全部线性层、解冻最后 4 块），训练损失越低（低 2–4%），Val 不升。带噪标签学习对这类现象有现成的描述：容量更大的网络在早学阶段之后会把错误标签也背下来，训练损失继续降，泛化不再变好（ELR §3；Self-Adaptive Training 图 1；ChronoSelect 摘要）。【推断】这提示新配方上的瓶颈可能部分转为「标签里的局部错误被背下来」，而旧配方中解码器和 VGG 容量有限，本身就背不下多少，所以那时针对标签噪声的做法看不出差别。由此得出两条重试原则：

1. 针对**标签噪声**的做法（筛选、去残差、按质量加权）在新配方上重试的理由最充分；
2. 重试时最好**同时**在「参照 LoRA」和「全部线性层 LoRA」两种容量上跑：若噪声处理在大容量上带来的提高更多，就直接支持上面的解释，也让此前白费的容量重新有用。

| 旧做法 | 旧配方上的结果 | 新配方上重试？ | 理由 |
|---|---|---|---|
| 换老师（LoFTR 第三轮 / RoMa 自己） | 0.304–0.306，持平 | **否**（单独做） | 老师 Val 从 0.259 换到约 0.29，学生不变；放开 DINOv2 不改变「学生对老师是谁不敏感」这一点。唯一的新变量是用新配方的学生（Val 0.322）当老师，见 P14，并且要和按稳定性筛选一起做 |
| 迭代（第二轮标签） | 0.304 / 0.306，持平 | **只在 P14 里** | 同上。单纯再打一轮，标签误差的结构与第一轮相同（同一个仿射拟合），没有新信息 |
| 学生侧几何 + 光度扰动 | 与不扰动相同 | **低优先** | Noisy Student 的论点是扰动在「学生容量足够」时才有用，放开 DINOv2 让这一条件略有改善【推断】。但光度扰动在 LoFTR 上就无作用；若要试，改用 P4 的「遮挡后仍监督」形式，信息量更大 |
| 筛选：前 50% vs 全部 | 0.306 vs 0.306 | **是**（便宜） | 属于标签噪声一类。容量更大时坏对更可能被背下来；硬切分与软加权（P1）各跑一次即可判断 |
| 粗层软目标（双线性分到相邻 4 格） | 0.312 vs 0.313 | **否**（固定宽度版） | 粗层量化不是瓶颈，这一点与特征端是否放开无关。宽度随标签不确定度变化的版本是 P11，信息不同 |

## 三、方法故事线

三条故事线针对本任务的三个具体困难，部件都来自上面的清单。每条都给出「最小可验证的版本」，便于第四批实验先试最便宜的部件；部件之间不互相依赖时，可以分别试、再叠加。

### 故事线 A：可匹配性感知的伪标签自训练

**针对的问题。** 月面光学与 SAR 之间存在大片本来就无法匹配的像素：光学图里的阴影、月海的弱纹理区、SAR 的叠掩和雷达阴影。全局仿射标签却在重叠区内给每个像素都指定了对应位置，并要求它们都有高 certainty。结果是两样东西被教错：细化层被要求在无法匹配的地方回归一个它看不出来的位置；certainty 学不到「能不能匹配」，推理时按 certainty 抽出的 1 万个点里混有这些像素，最后进入 RANSAC。

**流程。**
1. 打标：老师对每对跑 K 次（P10），得到每对的可信度和每像素的标签不确定度；同时用正反两个方向的往返一致性与伪仿射的一致性，得到每像素的可匹配掩码（P9）。
2. 用标：certainty 以可匹配掩码为目标（P9）；细化层多一个只在训练中使用的不确定度输出，回归损失用混合拉普拉斯（P5）；只在「标签比学生更有把握」的像素上监督回归（P12）。
3. 推理：网络不变，certainty 的含义变成「可匹配」，抽点更集中。

**组成。** P9 + P10 + P5 + P12（可选 P11）。

**可写的点。** 把「哪些像素能匹配」从标签里显式分离出来，并让它通过 certainty 抽点这一现成通道作用在最终的仿射估计上，推理零开销。现有稠密匹配器（RoMa、RoMa v2）的 certainty 都是由深度或真值重叠区监督的，在只有全局仿射伪标签的场景下没有对应做法【推断；本次检索未找到】。

**最小验证。** 先只做 P9（一次额外打标推理 + 1× 训练）。若 certainty 的含义变化本身带来提高，再加 P5、P10、P12。

**风险。** 往返一致和伪仿射一致这两个条件本身依赖老师；若老师在某类地形上系统性地错，掩码会把这类地形整片标成「不可匹配」，网络在那里永远学不会（2401.00850 提到的「只训练容易样本」问题）。缓解：掩码只用于 certainty，回归仍在全部重叠区内监督（P9 的基础版）。

### 故事线 B：防止背下局部错误的渐进式标签修正

**针对的问题。** 一对 patch 之间的真实对应并不是严格的仿射：地形起伏和 SAR 的斜距成像会造成随位置变化的偏移。全局仿射在局部有几个像素的错误，而且这些错误是有结构的（随地形变化），不是随机噪声。放开 DINOv2 后，学生把伪标签拟合得更紧，Val 却不升，符合带噪标签学习里「容量大的网络先学干净规律、再背下错误标签」的描述。

**流程。**
1. 训练前段照常用伪仿射监督（早学阶段）。
2. 从第 E 步起，回归目标逐步向「学生自己过去预测的滑动平均」过渡（P6）；粗层分类加早学正则（P7）；预测在训练中反复变化的像素降权（P8）。
3. 细层回归带容差，小于标签可信精度的误差不再罚（P2）。
4. 配套（不属于打标或用标）：用训练集上预测变化的曲线判断何时开始背噪声（Label Wave，2502.07551），作为不用 Val 的选存档依据，便于论文里说明整个流程不依赖标注。

**组成。** P6 + P7 + P8 + P2。

**可写的点。** 动机来自本任务自己的观察（放开得越多、训练损失越低、Val 不升），方法来自带噪标签学习，但把它从分类搬到稠密回归，并按 RoMa 的粗层分类 + 细层回归分别处理。

**可检验的预言。** 如果这条解释对，那么在全部线性层 LoRA 这类大容量设置上，这套做法的提高应当比在参照 LoRA 上更大；第三批中「没用上」的容量会重新变得有用。这一点可以和最小验证一起测。

**最小验证。** 先做 P6（或 P2），各在参照 LoRA 和全部线性层 LoRA 上跑一次。

**风险。** 学生自己的历史平均可能把它已有的系统偏差固化下来（上份调研的结论：自洽信号看不见一致的系统偏移）。P6 的混合系数不宜把伪仿射的权重降到 0。

### 故事线 C：由粗到细、由稳到全的课程式自训练

**针对的问题。** 伪仿射在「粗」的意义上可靠（RANSAC 在上万个匹配上做了平均），在亚像素的意义上不可靠；同样，有些对的标签很稳定，有些对在换种子、换方向、换尺度时就会变。现在的训练从第一步起就对所有被选中的对、所有尺度一视同仁。

**流程。**
1. 尺度课程：先只监督粗层和粗尺度的细化，之后再打开细尺度（P3），细尺度回归的容差随训练逐步收紧（P2）。
2. 上下文：训练中遮住部分区域，被遮处仍要预测（P4），让细化在弱纹理处依赖上下文而不是局部纹理。
3. 对级课程：第一轮只用 P10 判定为最稳定的对，训完用新学生重打标，逐轮放宽到更多对（P14）；每对按质量软加权（P1）。

**组成。** P3 + P2 + P4 + P1，扩展版加 P10 + P14。

**可写的点。** 把伪标签的两种可信度（尺度上的「粗准细不准」、对之间的「稳与不稳」）分别变成训练顺序，而不是变成门槛。STLD 在关键点回归上用过「由粗到细」的任务课程；本任务额外利用了 RoMa 本来就分尺度的结构。

**最小验证。** P3、P2、P4 都是 1× 且只改损失或输入，可以各跑一次；P14 成本最高，放在前面几项有结果之后。

**风险。** 旧配方上迭代与换老师都持平；P14 的多轮部分可能同样持平。尺度课程延后了细层的训练，在 8000 步内可能来不及收敛，需要按比例安排。

### 三条线的关系

A 处理「哪里能匹配」，B 处理「标签在能匹配处的局部错误」，C 处理「先学什么、后学什么」。A 主要改 certainty，B 主要改回归目标，C 主要改训练顺序，三者作用点不同，原则上可以叠加；但论文里每条线应能单独成立，消融放到最终配方的确认。
