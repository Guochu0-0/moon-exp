**实验目的**

LoFTR 上两条路线训练后 AUC 都有提升，但这些提升来自粗级匹配变好，还是细级精化变好，并不清楚。五个同类实验对 zero-shot 起点和四个训练后的模型分别只用粗级匹配估计仿射，与完整输出比较。本实验是外点扣分 −0.25 的两个种子这一份；五个模型放在一起的分析写在 zero-shot 起点的粗级评估实验里。

**实验方法**

模型取外点扣分 −0.25 两个种子各自第 1500 步的模型（只有粗级损失，细级专属权重与 zero-shot 相同），即按 Val 选定的那一步。只用粗级时，取粗级匹配的网格坐标（输入的 1/8，原图上约 6.4 px 一格），用 RANSAC 估仿射，阈值取主协议的 3 px 和更宽的 8 px 各一次。Val 和 Test 都评测，与完整输出比较。

**实验结果**

粗级 3 px 的 AUC@5：种子 0 为 Val 0.266、Test 0.224，种子 1 为 0.263、0.221；比完整输出低 Val 0.026 / 0.029、Test 0.042 / 0.047。相对 zero-shot，只用粗级的 Test 增益为 +0.059 / +0.056，完整输出为 +0.078 / +0.080。粗级 8 px 的 Val AUC@5 为 0.298 / 0.294，不低于完整输出；Test 为 0.257 / 0.252。

**实验结论**

约四分之三的增益只用粗级就能看到。细级权重没有动，细级的贡献却比 zero-shot 大约 0.02，来自更好的特征和粗匹配。两个种子的差不超过 0.005。
