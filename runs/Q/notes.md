## 定下的（助手暂定）

1. **粗级**：照 #49 的建议，RIPE++ 式 ±1 闭式期望（只对实际粗匹配给分）+ 负样本对（C2 形式），从 zero-shot 出发。
2. **优化配方**：AdamW lr 1e-5，warmup 500 步（从 0.1× 起）+ cosine 到 0，bs 1，不裁剪，4000 步，全部模块。
   warmup 用来对付 #49 里起步 10–100 步塌到「无匹配」；4000 步是因为 C 系峰值都在 1500 步以内。
3. **因素**（每组只在 Q0 上加一个）：
   - 细级闭式期望（Q1）：设计文档 5.1 (b) 的高斯策略，reward 取「到本步 RANSAC 仿射目标的负平方距离」时，期望有闭式解，
     梯度就是 soft-argmax 到目标点的 l2（只对落在 5×5 窗口内的匹配）。实现上 = 在线伪标签的细级项，粗级项关掉
     （`--w-pseudo 1 --w-coarse 0`；S2 的塌缩来自粗级稠密项）。
   - 细级逐匹配高斯 RL（Q2）：5.1 (b) 抽样版，σ_i 0.1，K 4，reward = 残差分级（`finetune/rl.py`）。
   - 细级整对 RL（Q3）：共享平移高斯策略（σ_i 0、σ_g 0.25，#27 里唯一可用的估计器），reward = 梯度幅值 NCC，K 4。
     这是唯一能看见整体偏移的信号。
   - 外点分值 −0.25（Q4）：起步塌到「无匹配」的另一种解法。
   - 熵正则、L2-SP 本轮不跑（#49 未见塌缩，L2-SP 暂不需要）。
4. **对照**：细级项各配随机 reward 对照（Q2p：逐匹配 reward 在匹配间打乱；Q3p：整对 reward 换成随机数），粗级项保留真 reward，
   这样对照只隔离细级项的作用。Q0 另跑一个种子（Q0s1）估种子间波动。对比方法：zero-shot（B0）、S1、C2。
5. **选模**：按 Val AUC@5 峰值（不含 step 0）选 ckpt，只对选中的 ckpt 补评 Test。ckpt：250、500、750、1000，之后每 500 步。
6. **成功判据**（暂定）：Val AUC@5 峰值高于 C2（0.285）至少 0.01，且高于对应随机对照，才算该因素有效；
   单种子差异 < 0.01 视为无法区分（C1、C2 的 bootstrap CI 半宽约 0.02）。

## 结论

**最好的形式是只用粗级：±1 闭式期望，外点分值 −0.25，加负样本对与 warmup（Q4）。两种子 Val AUC@5 后段均值都是 0.287，Test 0.266 / 0.268。
三种细级信号（闭式、逐匹配 RL、整对 RL）全都没有帮助。**

「后段均值」= step ≥ 2000 的 5 个 ckpt 的 Val AUC@5 均值（同配方两种子差 0.000–0.001，Q7 与 Q7s1 例外，差 0.007）。
Test 只评 Val 峰值 ckpt，同配方两种子 Test 可差 0.02，所以排序以 Val 后段均值为准。

逐条：
- **warmup 解决了起步塌到「无匹配」**：Q0 step 250 Val 0.260（C2 同步 0.225，更早几乎 0）；平台 0.278，比 C2 的 0.268 高且稳。
- **外点 −0.25 是本轮最大的单项增益（+0.009，两种子一致）**，起得也最快：Q4 step 250 就有 0.282。
  代价是向恒等的漂移最大：负样本对上的恒等匹配 3 → 约 60，正样本对 conf[i,i] 0.001 → 0.019（C1 峰值 44 / 0.009）；
  估出的仿射离 [I|0] 仍约 25 px，4000 步内 AUC 没有下降，还没塌，但要盯住。
- **学生侧扰动不提精度，但压住漂移**：Q5 的恒等匹配 0–3、conf[i,i] 约 0.001（回到起点）；Q7 相对 Q4 降到 5–15 / 0.004–0.007。
  Val 上 Q5 ≈ Q0 +0.004、Q7 ≈ Q4（两种子 0.284 / 0.291，均值 0.2875）。扰动过强（Q6）有害。
- **三种细级信号都不如不加**：细级闭式期望（Q1）−0.012；逐匹配 RL（Q2）−0.008；整对 RL（Q3 / Q3w）−0.007 / −0.004。
  随机 reward 对照（Q2p、Q3p）在 500–750 步内塌到 0 匹配、Val 0：细级 RL 项的梯度经共享的 backbone 足以摧毁粗匹配，
  真 reward 把它拉住了（说明 reward 里有信号），但净效果仍为负。与 #27「纯整对 RL 训全部模块会带崩粗匹配」一致。
- 与伪标签路线（`runs/P`）的最好结果相当：P8 后段均值 0.289、Test 0.263。两条路线的 SR@3 都在 0.33–0.37，离仿射地板（约 0.65）很远。

## 下一步（建议，待用户定）

1. 定本路线的底座：Q4（或 Q7：精度相同、漂移更小，更安全）。补跑更长（8000 步）看漂移会不会最终伤到 AUC。
2. 外点分值只试了 −1 与 −0.25，可以再扫 0、−0.1、−0.5；0 意味着「只奖励内点」，需注意是否更快漂向恒等。
3. 细级：本轮三种都失败。若还要做细级，应只训细级模块（`--train-modules fine`，#27 R27 的做法）或用单独 lr，隔离对粗匹配的破坏。
4. 两条路线都够不到系统偏移（`runs/P` 的 C6 检查：LoFTR 系与 RoMa 系偏移同向）。
