# 按原分布抽粗级锚点做策略梯度训练，连随机 reward 都会让粗级分布塌缩，两种无标注 reward 都没有超过 zero-shot

**摘要**

我们想在不用标注的前提下，用强化学习改进 RoMa 的月球光学–SAR 配准。具体做法是把粗级每个格子对 4096 个候选锚点的打分当作概率分布：每对影像从中抽 16 份样本，按 reward 在组内比较，再用策略梯度更新。此前的检查表明，zero-shot 模型的这个分布很平，抽样不缺探索，但训练起来能否学到东西还没有检验过。我们从 zero-shot 出发，用三种 reward 各训练两个种子，每个训练 4000 步。第一种是灰度 NCC reward，即按样本拟合出的仿射对齐两图后的灰度互相关。第二种是分级残差 reward，衡量每格的对应与样本自身仿射的一致程度。第三种是随机数，作为对照。灰度 NCC reward 先让 Val AUC@5 跌到 0.015 和 0.086，随学习率衰减才回升，到 4000 步为 0.234，与 zero-shot 的 0.236 持平。分级残差 reward 在训练中越来越高，配准却失效，配准误差的中位数升到约 100 px。随机 reward 的期望梯度为零，却在 1000–2000 步内把粗级分布压成几乎确定的单点，配准同样失效。没有一个模型超过 zero-shot，离同样扰动下离线伪标签自训练的 0.328 更远。按目前的步长，每一步更新本身就足以把粗级分布推离 zero-shot，reward 带来的信号被这种漂移淹没。

**引言**

月球光学影像与 SAR 影像之间没有可用的配准标注，因此我们只比较不需要标注的训练方法。目前最好的是离线伪标签自训练（noisy student）：用模型自己的高置信输出当标签，反复重训。在加大几何扰动（平移半径 128 px、旋转 ±20°、缩放 ±20%）的训练下，RoMa 用这种方法在 Val 上达到 AUC@5 0.328，zero-shot 为 0.236。伪标签只能教模型复现自己已经做对的部分。强化学习则可以直接按一个打分改进模型的输出，不受伪标签上限的约束，前提是这个打分本身不需要标注。

RoMa 先在粗级为每个格子从 64×64 个候选锚点中选出目标图上的落点，再逐级细化成逐像素的对应场。粗级的打分本身就是一个类别分布，可以直接抽样。此前的检查发现，zero-shot 模型的这个分布很平：按原分布抽样，96% 的格子落在概率最大的锚点之外；策略梯度能沿粗级回到 DINOv2 的低秩适配器。这说明抽样不缺探索，梯度也有去处。但两件事还没有检验：用不需要标注的 reward 训练能不能超过 zero-shot，以及训练是否真的由 reward 驱动。

本文按原分布抽样，用两种不需要标注的 reward 和一个随机 reward 对照，从 zero-shot 开始训练，比较它们在 Val 上的变化，并记录粗级分布在训练中的形状。

**方法**

*模型与数据。* 模型为 AnyMatch 发布的 RoMa 权重，DINOv2 每个块的 qkv 层挂秩 8 的低秩适配器，初值为零，因此训练开始时与 zero-shot 完全相同。训练集为 Train 的 7907 对，按离线伪标签自训练的加大扰动处理：SAR 一侧施加随机仿射（平移在半径 128 px 的圆盘内，旋转 ±20°，缩放 ±20%），再随机擦除 1–3 块，不加光度扰动。输入为 560²，粗级为 40×40 格。

*抽样。* 每步取 1 对影像，抽 16 份样本，温度为 1，即按原分布抽。每份样本在每个格子上独立抽一个锚点，代替概率最大的锚点（下称 mode）；粗级其余部分照推理计算，再照推理逐级细化成稠密对应场。细化不参与求导。

*Reward。* 三种 reward 都只用影像和样本自身。每份样本先按推理的做法拟合仿射：按 certainty 抽 5000 个点，RANSAC 阈值 3 px。

- 灰度 NCC reward：用这份仿射把 SAR 拉到光学网格上，在两图重叠、且不在 SAR 补零区域内的像素上计算灰度归一化互相关。拟合失败时记 −1。每份样本得到一个数。
- 分级残差 reward：每个像素到本份仿射的残差 r 代入 max(0, 1 − (r/3)²)，再在每个格子内平均。每个格子得到一个数。
- 随机 reward：每个格子取 0 到 1 之间的均匀随机数，与样本无关，作为对照。

*更新。* 每份样本（或每个格子）的优势是它的 reward 减去同组其余 15 份的平均（RLOO）。损失是负的优势乘所抽锚点的 log 概率，再取平均；不除以标准差，也不加约束模型靠近 zero-shot 的惩罚项。梯度经粗级回到低秩适配器、粗级解码器、粗级高斯过程和粗级特征投影，到不了细化层和 VGG。优化器为 AdamW，学习率 3e-5，权重衰减 0.01；先用 500 步从 0.1 倍升到全值，再按余弦衰减到 0，共 4000 步。每种 reward 用种子 0 和 1 各训练一次。

*评测。* 每 1000 步存一次权重，在原始 Val（652 对）上评测。配准误差是估计的仿射与标注之间 patch 四角的平均距离。AUC@5 是误差在 0–5 px 内的累计成功率曲线下的面积，按 5 px 归一化。每个训练按 Val AUC@5 的峰值选权重（不含第 0 步），再在 Test（953 对）上评测。参考值取同一扰动范围下训练的结果：RoMa zero-shot 在 Val 和 Test 上为 0.236 和 0.231，离线伪标签自训练为 0.328 和 0.301。

*粗级分布的形状。* 训练中每步记录两个量，并在 100 步的窗口内平均。一是每格的熵，以 e 为底，在 4096 个锚点上均匀分布时为 8.32。二是 mode 的概率。

**结果**

*灰度 NCC reward 先让配准变差，随学习率衰减才回到 zero-shot 的水平。* 训练 1000 步时，两个种子的 Val AUC@5 分别跌到 0.015 和 0.086（表 1）。之后学习率逐渐变小，AUC@5 逐步回升，到 4000 步两个种子都是 0.234，与 zero-shot 的 0.236 持平。在 Test 上为 0.222 和 0.218，略低于 zero-shot 的 0.231。种子 0 的粗级分布在 1000 步附近一度塌缩，熵为 0.56，mode 概率为 0.90；这时每份样本的平均 reward 也降到 −0.064。之后分布重新变平，到最后熵为 3.6（表 2）。

*分级残差 reward 越训越高，配准却失效。* 种子 0 的平均 reward 在 1000 步附近从 0.10 升到 0.30，同时 Val AUC@5 在每个存档上都是 0，配准误差的中位数为 92–118 px。种子 1 在 1000 步时还有 0.214（Test 0.192），仍低于 zero-shot；到 2000 步跌到 0.015，之后误差的中位数为 101–113 px。两个种子的熵都降到 1 左右，mode 概率在 0.63–0.69。

*随机 reward 同样让粗级分布塌缩，配准失效。* 随机 reward 与样本无关，它的期望梯度为零。但种子 0 的熵从 5.5 降到 2000 步时的 0.002，mode 概率接近 1；种子 1 塌缩得更早，1000 步时熵已为 0.04。两个种子在 1000 步以后的 Val AUC@5 都在 0.012 以下，误差的中位数为 148–309 px。

**讨论**

按原分布抽粗级锚点、从 zero-shot 开始做策略梯度训练，本文的设置下学不到东西。随机 reward 的对照说明了原因：它不含任何关于样本好坏的信息，却在 1000–2000 步内把粗级分布压成单点。每一步更新带着抽样的噪声，以目前的学习率，这些噪声累积起来就足以把模型推离 zero-shot，而且推向更尖的分布。在这种漂移之上，灰度 NCC reward 是唯一能把模型拉回来的 reward，但只拉回到 zero-shot 的水平。分级残差 reward 只要求每格的对应与样本自己的仿射一致：一个整体错位、但各处错得一致的对应场也能拿到高分。所以它的 reward 上升、配准却失效。由于随机 reward 也会塌缩，本文分不清分级残差 reward 的失效有多少来自它本身的这一缺陷，有多少来自同样的漂移。

局限有三点。第一，本文只用了一个温度（1）、一个学习率（3e-5）、每步一对影像，训练 4000 步，没有检验更小的更新步长或更多步数。第二，每种 reward 只有两个种子，两个种子之间差别很大：分级残差 reward 在种子 1 上 1000 步时还正常，在种子 0 上已经失效。第三，对已经失效的训练，按 Val 峰值选出的权重只是失效最轻的那一个，它的 Test 数字不代表这种 reward 的能力。

在比较任何 reward 之前，先要让随机 reward 的训练保持在 zero-shot 附近。否则 reward 的作用与更新本身造成的漂移混在一起，无法读出。值得检验的做法有三种：减小每步更新的幅度，例如降低学习率，或每步用更多影像对；加入约束模型靠近 zero-shot 的惩罚项；以及按此前检查的建议把采样温度降到 0.3 左右，让样本更接近推理时的输出。只有随机 reward 在这些设置下保持平稳，灰度 NCC reward 与 zero-shot 的差距才说明 reward 本身的作用。
