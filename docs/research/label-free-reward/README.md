# 无标注 reward 候选：光-SAR 仿射配准的 RL 微调能用什么信号

> 调研日期：2026-09-27。回答 [#22](https://github.com/Guochu0-0/moon-exp/issues/22)（map：#1）。
> 前提：在 AnyMatch-LoFTR（半稠密）或 AnyMatch-RoMa（稠密）上，用单步（bandit）policy gradient 微调，做法类似 RIPE / DISK；月面光学–SAR patch 对已粗对齐，目标变换是仿射；训练集没有任何标注；RL 的卖点立在「不可微」（RANSAC、离散选择）上，不立在「无标签」上。瓶颈：粗对齐能做到（SR@10 约 85%），3 px 以内精度差（SR@3 约 30%）。
> 标注约定：**【读到】** = 读过论文原文或代码（出处见 [sources.md](sources.md)）；**【推断】** = 我的判断。
> 不重复：[`rl-registration-survey.md`](../rl-registration-survey.md)（RIPE / DISK / RFP / FeMIP、「RL 的合法性来自不可微」）和 `research/matcher-rl-feasibility` 分支（LoFTR/RoMa 里 policy 放在哪、RIPE++ 的闭式期望、训练代码与成本）。这两份讲过的内容这里只引用结论。

## 0. 结论速览

1. **信号可以分成两类，这决定 RL 有没有必要。** 一类可以拆成**逐匹配**的分数：RANSAC 内点/外点、到自估仿射的残差。它们本质上是「自己估几何，再把几何当伪标签」，已有**不用 RL** 的做法（SCENES 的 bootstrap：RANSAC 估出几何，再用可微的极线损失微调 LoFTR 系匹配器）。另一类只能在**整对图像**上给一个标量：warp 后的跨模态相似度、变换一致性误差、子集间仿射是否一致。这一类没法摊到单个匹配上，要做信用分配，policy gradient 才真正有用。
2. **所有「自洽」类信号都看不见系统性偏移。** 内点数、残差、cycle / 等变一致性，只要整套匹配**一致地错**（比如整体偏 2 px），就全部满足。WarpC 对一致性约束的分析给出了这一点的理论依据。月面光学与 SAR 的成像几何不同（太阳方位 vs 雷达视向），可能让同一个撞击坑边缘在两种模态里定位就不一样【推断】。**SR@3 的瓶颈如果主要是系统性误差，自洽类 reward 就无能为力**，只有直接比较图像内容的信号（结构特征相似度）或外部锚点能纠正。
3. **二值内点数在阈值以内没有梯度。** 3 px 以内的精度要靠按残差分级的 reward：RIPE++ 用截断二次核，按 Sampson 距离给连续分数，消融显示比二值好。另外 RIPE++ 报告「RANSAC 内点数上升，但位姿精度没有跟着上升」，这是内点类 reward 被钻空子的直接证据。
4. **warp 后相似度（CFOG / MI / NCC）可以用，但会塌，而且本身可微。** 在多模态上端到端优化相似度，塌到「编码器输出常数 + 预测恒等变换」有明确记录（AltO）；在 OPT-SAR 上，一批无监督单应方法的 MACE 停在恒等变换的水平，或者根本不收敛（SSHNet 表 5）。MU-Net 用 CFOG + NCC 做损失，在 Sentinel 光学–SAR 上**直接反传**就训出来了，所以「相似度 + RL」一定会被问「为什么不直接当 loss」。只有当相似度作用在 **RANSAC 输出的仿射**上时，它才是不可微链路里的 reward。
5. **变换一致性（A₂ = T∘A₁）单独用很弱。** 它对应 WarpC 分析过的一类约束：对常数偏置不敏感；T 越接近恒等，信号越弱。T 是纯平移时，对平移偏差完全没有信号。它是训练稳定化的辅助项（DCFlow 就这么用），不能单独当主 reward。
6. **月面上的已知难点**：Mini-RF 的 SAR 缺角点、边缘模糊、局部信噪比低，和光学/DEM 参考之间的信息差比地球 SAR 更大；NCC、MI 这类灰度方法只适合辐射差异小的场景【读到，RS 2025】。所以内点类 reward 天然会把匹配往撞击坑边缘这些少数有纹理的区域集中；RIPE 靠网格化采样、NG-DSAC++ 靠学会忽略无纹理区域来应对。
7. **成本**：仿射的最小集只有 3 个点，同样内点率下 RANSAC 迭代次数比 RIPE 的 F 矩阵（7/8 点）少一到两个数量级。每对图 K 次采样就是 K 次 RANSAC；变换一致性要翻倍（两次前向、2K 次 RANSAC）；SCENES 式伪标签可以离线一次算完。

## 1. 先要分清：误差是系统性的还是随机的

这是选 reward 前最该先回答的问题【推断】。

- 如果 3 px 级的误差是**逐匹配的随机噪声**（亚像素定位抖动、少量外点），那么「到自估仿射的残差」这类自洽信号就有效：RANSAC 在大量匹配上做了平均，自估仿射比单个匹配准，残差把单个匹配往这个一致解上拉。SCENES 的观察和这一点吻合：bootstrap 带来的提升「主要来自提高匹配之间的一致性」，而且在基础模型本来就失败的图像对上提升最弱【读到，SCENES §附录】。
- 如果误差是**整对一致的偏移**（跨模态的定位偏差、SAR 斜距几何带来的局部位移），那么一套一致地偏了的匹配，内点率和残差都很好，cycle / 等变一致性也都满足（见 §2.D）。这种情况下自洽类 reward 会**强化**错误。

**可以马上做的诊断**【推断】：在带真值的评测集上，对每对图像比较两个量：(i) 匹配相对**自估** RANSAC 仿射的残差（自洽噪声）；(ii) 自估仿射相对**真值**仿射的误差。如果大部分 SR@3 失败的样本都是 (i) 小而 (ii) 大，那么瓶颈是系统性的，内点类 reward 不会解决问题，应该把重心放在跨模态相似度或锚点信号上。这个诊断不用训练，用 #3 的 baseline 输出就能做。

## 2. 候选信号逐类

### A. 自身 RANSAC 内点 / 残差（RIPE 式）

**文献里怎么用【读到】**
- RIPE（ICCV 2025）：MNN + RANSAC 估 F，按同场景/不同场景给正负 reward（详见已有调研 A 节）。
- RIPE++（arXiv:2608.19693）：只用正样本对，内点 +、外点 −。之所以去掉负样本，是因为 RIPE 在「全部匹配都被 RANSAC 拒掉」的极端情况下梯度是中性的。除此之外还有两点。(1) **退化解**：reward 只作用在匹配上的关键点，网络可以把所有关键点都预测为「不可匹配」来躲开惩罚，所以要给每个被判为不可匹配的点加一个小惩罚。(2) **分级 reward**（附录）：`r = 1 − ½(d_S/δ)²`（d_S ≤ τ 时），否则取 ρ_out，d_S 是 Sampson 距离。离极线越近奖励越高；RANSAC 阈值 1.5 时，d_S > 1.41 的内点已经拿到小惩罚。消融中「distance-based reward」单独使用有提升。(3) **钻空子的证据**：把描述子损失换掉后，「RANSAC 内点数明显增加，但没有转化成位姿精度的提升」。(4) 正则权重要仔细调，取 1e-5 时性能下降，取 1e-4 时训练崩溃。
- NG-RANSAC（ICCV 2019）：用**最终估计的内点数**当自监督任务损失，训练 RANSAC 的采样分布，梯度是 REINFORCE 加 baseline。原文说内点数「是很稳定的训练信号，训练初期也一样，不需要特殊初始化」。自监督版略差于有监督版，但与 USAC 持平。训练时每张图 K=4 个假设池，每池 M=16 个假设。NG-DSAC++ 在 Cambridge 数据上学会了忽略天空和草地：「网络在这些区域预测不准，所以学会把它们遮掉」。

**四点评估**
- (a) 可以拆成逐匹配 reward。RIPE++ 就是按匹配给 ±，还能用 dual-softmax 概率算闭式期望，不用采样。**【推断】** 这一拆，它就和「RANSAC 伪标签 + 加权交叉熵」几乎等价，RL 的必要性只剩「匹配选择（阈值、MNN、multinomial）本身不可微」这一条。评审可以拿 SCENES（§B）当反例。
- (b) 钻空子：①把所有点标成不可匹配或只出很少的匹配（RIPE++ 用不可匹配惩罚）；②把匹配堆到少数高纹理、一致性好的区域，内点率高，但仿射外推差【推断；NG-DSAC++ 的「忽略难区域」是同一机制的正面版本】；③**一致但有偏**的匹配集（见 §1）；④F 矩阵情形下塌到对极点（RIPE 补充材料，已有调研已记）。仿射没有对极点，但有类似的退化：大部分匹配落在一条线上时，仿射欠定【推断】。
- (c) 低纹理和辐射差异：内点数只要求「几何一致」，不要求「外观相似」，对辐射差异本身不敏感。但低纹理区域出不了匹配，reward 只能来自撞击坑这类结构。月面 SAR 缺角点、边缘模糊【读到，Mini-RF 配准论文】，预计有效匹配少，reward 方差大【推断】。
- (d) 每次采样 1 次仿射 RANSAC。仿射最小集 s=3，按 `N = log(1−p)/log(1−w^s)`，w=0.5、p=0.99 时 N≈35；F 矩阵 s=8 时 N≈1177【推断，标准公式计算】。组内 K 次采样就是 K 次 RANSAC；用 RIPE++ 式闭式期望时，每对只要 1 次。

### B. RANSAC 几何当伪标签，配可微损失（SCENES bootstrap）——RL 的直接竞争者

**【读到】** SCENES（3DV 2024，arXiv:2401.10886）把 LoFTR 系匹配器（MatchFormer、ASpanFormer）的对应点损失换成极线损失：粗级是分类损失，细级是回归损失。没有位姿时就 bootstrap：「用预训练模型在新域上得到（质量差的）对应，再用 RANSAC 估 F，把它当极线损失的监督」。核心直觉是「即使很多匹配是错的，鲁棒估计器在很多情况下仍能估出大致正确的 F，从而给错误匹配提供监督」。只保留匹配 ≥100、内点 ≥20 的图像对；F 用 OpenCV RANSAC 离线算一次。作者把「每隔几个 epoch 重估 F、迭代 bootstrap」列为未来工作。位姿加 1–2° 扰动，性能就明显下降。

**四点评估**
- (a) 本身就是逐匹配的可微损失，不需要 RL。**【推断】** 换到我们的场景很直接：RANSAC 估仿射 → 对粗级置信矩阵用「落在仿射预测点附近」做分类目标，对细级用「到仿射预测点的距离」做回归。这是 RL 方案**必须对比的 baseline**。RL 要赢，必须用到它做不到的东西：整对级的不可微 reward（§C、§D 的整对版本）或离散选择。
- (b) 自我强化：伪几何错了就一直错。SCENES 用最少匹配数/内点数过滤，但它自己说对「基础模型本来失败的对」帮助最弱。
- (c) 同 A：伪几何的质量受限于基础模型在低纹理对上的表现。
- (d) 每对 1 次 RANSAC，可以离线预计算；在线 0 次。

### C. warp 后跨模态相似度（CFOG / MI / NCC）

**【读到】**
- MU-Net（TGRS 2022 / ISPRS 2022）：无监督多尺度仿射回归。损失 `exp(−[Sim(f, T(m)) + Sim(T⁻¹(f), m)]/2)`，双向对称。Sim 是在 **CFOG 结构特征图**上算的 NCC；理由是「光学–SAR 的像素灰度不能直接比较，但结构特征在多模态间保留」。在 Sentinel-1/2（10 m）光学–SAR 上训练约 5000 对。训练对是对齐图像加随机仿射得到的。作者指出 CFOG 模板匹配对旋转敏感；端到端回归的通病是初始畸变越大，误差越大。
- AltO（NeurIPS 2024）：在多模态上「编码器 + 配准网络」同时用重建/感知类损失训练，会「塌成平凡解：编码器输出常数，配准网络预测恒等矩阵」。他们用交替优化加 Barlow Twins 防塌。
- SSHNet（arXiv:2409.17993）：在 OPT-SAR 上，「没有问题重构时，用灰度监督的无监督训练不收敛」。表 5 里 UDHN、CA-UDHN、biHomE 等的 MACE 在 OPT-SAR 上约 24–27 px 或 NC（不收敛）；作者在 AltO 中说明 MACE > 23 px 相当于恒等变换，即训练失败。
- WarpC 引言：光度一致性假设在大外观变化下失效。
- 月面：Mini-RF 配准论文指出 NCC、MI 这类灰度方法「适合辐射/几何差异小的场景」；它的做法是先用 DEM 模拟 SAR 图，再和真实 SAR 做 NCC，而不是直接和光学比。

**四点评估**
- (a) **不能拆成逐匹配**：相似度是对整张 warp 后的图算的标量。**【推断】** 当 warp 用的是 RANSAC 从采样匹配里估出的仿射时，「匹配 → RANSAC → warp → 相似度」这条链路不可微，这是 RL 名正言顺的用法。但评审会问：能不能用可微的加权最小二乘仿射（或 ∇-RANSAC，ICCV 2023，可以训特征检测与匹配网络）直接反传相似度？答案是可以（MU-Net 就是直接回归仿射再反传），所以这条论证要落在「匹配选择的离散性」上，不能落在「相似度不可微」上。
- (b) 钻空子：①塌到恒等或常数（AltO、SSHNet）；我们的数据已经粗对齐，恒等附近本来就是一个高相似度的局部极值，这一风险更大【推断】；②仿射缩放/裁剪使重叠区域落在均匀区，NCC 虚高。MU-Net 用双向对称损失，**可能**就是为了防这个【推断，论文没说明动机】；③结构特征（CFOG 基于梯度方向）在月面上主要响应撞击坑的阴影边缘，而光学阴影方向由太阳决定，SAR 的明暗由雷达视向决定，两者的「结构」不一定对应同一条物理边界【推断】。
- (c) 已知失效：灰度 MI/NCC 在光学–SAR 上失效（SSHNet、MU-Net 引言、Mini-RF 论文）。CFOG 在地球光学–SAR 上有效（MU-Net），在月面没找到验证。
- (d) 每次采样 1 次 RANSAC + 1 次 warp + 相似度计算。CFOG 特征可以对固定图预计算，NCC 可以用 FFT 在 GPU 上算，预计比 RANSAC 便宜【推断，未实测】。

### D. 变换一致性 / 等变（人为施加 T，检验 A₂ = T∘A₁）

**【读到】** WarpC（ICCV 2021）对「真实对 (I, J) + 一侧加已知 warp W」构成的三元组，推导了全部一致性约束，并逐一分析：
- I′J-bipath：`M_{I′→J} = M_{I→J} ∘ W` 类的约束「有退化平凡解」：把所有点映射到同一个常数点，对任何 W 都成立。
- JI′-bipath（`F_{J→I′} = F_{J→I} + …(W)`）：两次预测里的误差互相抵消，「对预测里的常数偏置不敏感」；偏置 b 带来的损失增量大约只和 `D_W·b` 成正比，W 平滑、雅可比小时可以忽略；W→0 时「完全没有学习信号」。
- W-bipath（经 J 绕回 I′，要求合成等于 W）：随机的非零 W 避开了 forward-backward 一致性的退化解，也没有偏置抵消。但它单独用时在 PCK-1 上不如 warp-supervision，两者组合最好。forward-backward 损失权重调高会「把网络推向零」。
- DCFlow（arXiv:2509.24423）：对跨模态对两边同时施加随机仿射，要求前后预测的 flow 一致，**作为联合优化项**，主监督来自模态翻译加单模态合成监督。

**对应到我们的候选【推断】**：「对 SAR 施加 T，要求 O→T(S) 的仿射 A₂ 等于 T∘A₁」属于 WarpC 的 JI′ 型：两次预测都经过同一个跨模态映射。若网络对 O→S 有一个一致的偏差 E（A₁ = E∘A*），那么只要它对 T(S) 也给出 T∘E∘A*，约束就成立，且代价只取决于 E 与 T 是否可交换。平移偏差与纯平移的 T 可交换，所以**对平移偏差完全没有信号**；T 的线性部分越接近单位阵，信号越弱。这正好是 3 px 瓶颈最可能的形态。

**四点评估**
- (a) 整对级的仿射误差 ‖A₂ − T∘A₁‖ 是标量，要做信用分配，适合 RL；也可以在匹配层面写成「O 中的点经 A₁ 再经 T，与经 A₂ 是否落在同一位置」，但这需要两个 RANSAC 的结果，仍然不可微。
- (b) 钻空子：一致但有偏的解（上面分析）；如果 A₁、A₂ 各自都能在不看 O 的情况下只由 S 侧决定，就存在不看跨模态内容的捷径（对应 WarpC 的平凡解）【推断】。文献的防法：用 W-bipath 形式，再配合一个直接监督项（warp-supervision / 单模态合成监督）。
- (c) 不直接依赖外观，但 T(S) 的插值会改变 SAR 散斑的统计，网络可能学会识别「被变换过的图」【推断】。
- (d) 每个样本 2 次前向、2 次 RANSAC；组内 K 次采样就是 2K 次 RANSAC。

### E. teacher–student 伪标签 + 几何过滤

**【读到】**
- 事件–图像无标签目标域自蒸馏（arXiv:2607.10082）：teacher 用预训练模型初始化、EMA 更新；student 输入单应增强后的对，teacher 输入原图；两者预测交叉验证，取一致的匹配当伪标签。原文说「只依赖网络输出一致性有误差累积（confirmation bias）的风险」，所以对 teacher 匹配跑 RANSAC 估 F，用极线距离给蒸馏损失加权。底座是 SuperPoint 式稀疏特征。
- Self-Improving VO（DeTone et al., arXiv:1812.03245）：用 VO 后端的重投影误差标注关键点「稳定/不稳定」，再回训前端；也就是用自己的输出加多视几何造监督。
- 已有调研里的 CoLReg（扩散翻译 + 伪标签交替训练）、半监督 SAR-光学多尺度匹配（arXiv:2508.07812）也属于这一类，这里不重复。

**四点评估**
- (a) 逐匹配、可微，不需要 RL。
- (b) 确认偏差 / 误差累积是公认风险；防法是 EMA teacher、增强视角间的一致性过滤、外部几何（RANSAC）加权。
- (c) 伪标签的质量受 teacher 在低纹理对上的表现限制，和 B 一样。
- (d) teacher 1 次无梯度前向 + 1 次 RANSAC。

### F. 模态翻译 + 同模态自监督（SSHNet / DCFlow / CoLReg / AltO）

**【读到】** 这几篇的共同结论：跨模态无监督时，直接用外观损失端到端训会塌或不收敛；可行的做法是把问题拆成「模态翻译」和「同模态几何估计」，分开或交替训练。SSHNet 报告同时训练两个子网络「不收敛」，必须分开优化。
**【推断】** 这一类要额外训练翻译网络，成本和工程量都大，与「在 AnyMatch 权重上轻量微调」的定位不合，也不产生不可微 reward。列在这里是为了说明：纯无监督的跨模态几何学习，文献里几乎都要借助额外结构来防塌。

### G. 合成 warp 监督（单图 + 已知变换）

**【读到】** WarpC：warp-supervision「受益于直接监督，但缺少真实图像对，往往泛化差」；它的 PCK-1 高但对大视角变化不鲁棒。MU-Net、ACAMatch 的训练对也来自已知合成变换。
**【推断】** 对光学–SAR，单图 warp 只能教同模态，教不了跨模态的偏差，但能给**亚像素级的精确目标**。可以作为辅助项防止微调时细级精度退化，不能当 RL reward（它有精确标签，直接监督就行）。

### H. 跨模型一致性

AnyMatch 用 RoMa 的 PCK 给合成数据做质检，MatchAnything 用 RoMa 跟踪造视频伪标签（见 `matcher-rl-feasibility` 第 3、5 节）。**【推断】** 在我们的场景里可以把「LoFTR 系与 RoMa 系两个底座各自 RANSAC 仿射的一致度」当整对级 reward 或过滤条件。它能部分缓解单模型的自我强化，但如果两个模型有同样的跨模态偏差（训练数据同源，都来自合成多模态），也纠正不了系统误差。没找到直接先例。

## 4. 对「RL 卖点」的含义

**【推断】**
1. 只用 A 类（可拆）reward 时，方法和 SCENES 式伪标签自训练的差别只在于「匹配选择的离散性」。这个卖点成立（LoFTR 阈值 + MNN、RoMa multinomial 都是 `no_grad`），但增量小，而且必须和 B 做对比实验。
2. 要让 RL 站得住，至少要有一个**整对级、经过 RANSAC 的**reward 分量，比如「RANSAC 仿射 warp 后的 CFOG-NCC」或「两个不相交匹配子集各自估的仿射是否一致」（子集一致性：没找到先例，只是一个候选），再配合组内 baseline（GRPO 式）压方差。
3. 从防钻空子的角度，比较合理的组合是：逐匹配的分级残差（A′，稳定、低方差）+ 整对级的跨模态结构相似度（C，唯一能看到系统性偏移的信号）+ 空间覆盖约束（网格采样或覆盖率惩罚）。变换一致性（D）只当辅助项。
4. §1 的诊断应该在选 reward 之前做：它决定 A 类 reward 能不能碰到 SR@3 的瓶颈。
