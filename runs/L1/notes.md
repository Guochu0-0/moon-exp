# DINOv2 加 LoRA 之后，自训练只用伪标签最可信的一半对仍然最好，用全部对明显变差

**摘要**

RoMa 的自训练用 RoMa 自己给每对影像估的一个仿射作伪标签，一直只用内点数最多的前一半对。给 DINOv2 加 LoRA 之后，模型能把伪标签拟合得更紧，伪标签里的错误可能因此危害更大，也可能因为模型更强而被容忍，更多的对就能派上用场。我们在这一配方上比较了三种选对的方式：只用前一半（基准配方）、通过基本门槛的对全部使用、全部使用但每对的损失乘以它的内点比例。全部使用时 Val 平均 AUC@5 从 0.322 降到 0.312，降幅达到 0.01 的显著标准；按内点比例加权收回了大部分，为 0.319，仍低于基准配方。新增的那一半对，模型在训练末期也拟合不了：在 1 倍分辨率上，与伪标签的中位误差从 0.94 px 升到 1.50 px。把 LoRA 扩展到 DINOv2 每块的全部线性层后，按内点比例加权仍比同一容量的基准配方低 0.002。在这一配方上，选对仍应只取前一半；其余对的伪标签以错误为主，靠加权利用不了。

**引言**

RoMa 自训练的监督来自 RoMa 自己：零样本的 RoMa 在每对训练影像上抽 1 万个匹配，用 RANSAC 拟合一个全局仿射，这个仿射就是这对影像的伪标签。匹配不少于 100 个、内点不少于 20 个的对通过基本门槛；训练只用其中内点数最多的前一半。此前 DINOv2 冻结时，这一选择影响不大：只训解码器时，全部使用与只用前一半持平；解冻 VGG、学习率 3e-5 时，全部使用低 0.007（一个种子）。给 DINOv2 每块的 qkv 加秩 8 的 LoRA 之后，Val 平均 AUC@5 升到 0.322；扩大 LoRA 的范围能进一步降低训练损失，却不再提高 Val。一种解释是，更强的模型开始记住伪标签里的错误。如果这样，坏标签的危害在新配方上会更大，选对会更重要；反过来，更强的模型也可能从更多的对里获益。本实验在新配方上重新比较选对的方式，并检验按标签质量加权能否兼得两者。

**方法**

*基准配方。* 起点是 AnyMatch 发布的 RoMa 权重，SAR 逐 patch 做 min–max 归一化。监督是上述伪仿射，只用内点数最多的前一半对，共 3954 对。优化用 AdamW，权重衰减 0.01，batch 1，训练 8000 步，每 1000 步存一次。学习率 3e-5，前 500 步线性升起，之后余弦降到 0。解码器与 VGG 一起训；DINOv2 每块的 qkv 上加秩 8、α 16 的 LoRA，学习率 1e-4。损失是 RoMa 原本的监督：粗级的锚点分类、各尺度的 certainty 和细化回归，真值都由伪仿射给出；每步以 0.5 的概率交换光学与 SAR 的方向。

*三种选对方式。* 只用前一半即基准配方。全部使用：通过基本门槛的对都参与训练，其余不变。按内点比例加权：同样全部使用，每对的损失乘以它的内点数除以匹配数，再在训练集上归一化到均值 1；权重最小 0.09、最大 2.60。加权的做法取自 DAFormer（2111.14887）用伪标签置信度给损失加权的思路，这里在对的层面上使用。

*更大容量上的对照。* 按内点比例加权另在一个更大的配方上跑一次：LoRA 加到 DINOv2 每块的全部线性层（qkv、注意力输出投影、MLP 的两层），其余不变。它与同一容量的基准配方比较，后者此前已经跑过，Val 平均 AUC@5 为 0.3218。

*对照与种子。* 基准配方在本实验的代码上用种子 0 重跑一次。所有方法都只跑种子 0，因此数据顺序相同。

*评测。* 每个存档在 Val 上算 AUC@5。我们比较第 2000 步到第 8000 步 7 个存档的平均值，下文称 Val 平均 AUC@5。一个方法要被保留，需要至少 2 个种子都比基准配方高 0.005 以上；只有第 1 个种子高出 0.005 时才补第二个种子。Test 只在 Val 最高的那一步评测，只作记录。训练末期的拟合程度用第 7000–7999 步的平均训练损失，以及 1 倍分辨率上预测落点与伪标签落点之差的中位数（原网格像素）衡量。

**结果**

*全部使用明显变差，按内点比例加权也不及只用前一半。*

| 方法 | Val 平均 AUC@5 | 与基准配方之差 | Val 最高（步） | Test（该步） |
|---|---|---|---|---|
| 只用前一半（基准配方，重跑） | 0.3218 | — | 0.325（3000） | 0.296 |
| 只用前一半，此前三次运行 | 0.3220 / 0.3225 / 0.3221 | 0.000 – +0.001 | 0.325 / 0.325 / 0.326 | 0.299 / 0.300 / 0.300 |
| 全部使用 | 0.3117 | −0.010 | 0.317（8000） | 0.287 |
| 全部使用，按内点比例加权 | 0.3188 | −0.003 | 0.323（7000） | 0.295 |

表 1：在 DINOv2 加 LoRA 的配方上，只用前一半对的 Val 平均 AUC@5 最高；全部使用低 0.010，加权后仍低 0.003。

*新增的对，模型在训练末期也拟合不了。* 第 7000–7999 步，只用前一半时平均训练损失为 1.20，1 倍分辨率上的中位误差为 0.94 px；全部使用时分别为 3.50 和 1.50 px。按内点比例加权时，训练损失降到 1.81，但它只是把难拟合的对的损失按权重缩小了，中位误差同样是 1.50 px。

*在更大的容量上，加权同样没有提高。* LoRA 加到全部线性层时，按内点比例加权的 Val 平均 AUC@5 为 0.3195，同一容量的基准配方为 0.3218，低 0.002。

**讨论**

在 DINOv2 加 LoRA 的配方上，选哪些对进训练比此前更重要：多用的一半对使 Val 平均 AUC@5 降低 0.010，而在冻结 DINOv2 的配方上，这一差别最多 0.007。加入这些对以后，模型训练到最后仍拟合不了伪标签，中位误差比只用前一半时大 0.6 px，说明它们的仿射多半是错的，而不只是难学。这一判断是推测：本实验没有逐对检查新增的对。按内点比例加权只能减轻这种伤害，不能把它变成收益：内点比例低的对权重已经很小，但只要还参与训练，就仍有坏处。

局限：每种方式只有一个种子、一档设置；加权只试了内点比例一种质量度量，也没有试介于一半和全部之间的比例，或比一半更严的筛选。

这一结果提示，在这一配方上，伪标签侧可能更值得在「选哪些对」上下功夫，而不是改变标签怎样进入损失：例如用更可靠的度量判断一对的标签是否可信（多次打标是否一致），或比一半更严地筛选。
