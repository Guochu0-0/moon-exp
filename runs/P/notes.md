本实验是伪标签路线的两轮训练实验，以 Noisy-Student 式的迭代自训练为主。实验分两部分：实验一试迭代打标、学生侧扰动和筛选；实验二在实验一的基础上进行一些改动与探究。

文中「第 n 轮标签」指第 n 次生成的伪标签：第一轮由 zero-shot 起点生成，即离线伪标签实验所用的标签；第二轮由离线伪标签实验第 6000 步的模型生成；第三轮由本实验「第二轮标签 + 扰动」第 7000 步的模型生成；第四轮由「第三轮标签 + 扰动」第 7000 步的模型生成。

## 实验一：Noisy-Student 式迭代

**实验目的**

离线伪标签实验很快进入平台期：用它自己的模型重新生成一轮伪标签再接着训，也停在原处。

调研迭代自训练的文献发现，多轮能继续提高的做法都给学生注入了新东西，例如更难的输入、从头重训、扩大数据或换一个老师；推测重新打标不涨，是因为老师和学生过于相似。Noisy-Student（arXiv:1911.04252）的做法正好满足这些条件：用更好的老师在干净输入上打标签，学生从头训练，并在学生的输入上加扰动。

按这个做法训练，拆开看「更好的老师」和「学生侧扰动」各自的作用，再试筛选和继续迭代。

**实验方法**

学生都从 zero-shot 起点重新训练。损失和伪标签的筛选与离线伪标签实验相同。

训练时网络保持推理模式，训练全部模块。优化器为 AdamW，学习率前 500 步从 1e-6 线性升到 1e-5，之后按余弦曲线降到 0，batch 1，共 8000 步。

伪标签的筛选沿用 SCENES 的规则：匹配少于 100 个或内点少于 20 个的对不用。

学生侧扰动：给 SAR 施加已知的随机仿射（平移 ±12 px，约两个粗网格；旋转 ±3°；缩放 ±3%；图外补 0），标签相应地精确变换；两侧再加光度扰动（gamma、对比度，SAR 加乘性散斑，光学加高斯噪声，轻微模糊）。

各方法：

- 第二轮标签，无扰动：只换更好的老师。
- 第一轮标签 + 扰动：只加扰动。
- 第二轮标签 + 扰动：两者都有；另换一个种子。另有一个方法只用几何扰动，不加光度扰动。
- 第二轮标签 + 扰动，只用内点数排在前 50% 或前 25% 的对：先学容易的对。前 50% 的方法另换一个种子。
- 第三轮、第四轮标签 + 扰动，各自分别用全部对和内点数前 50% 的对。

对照是离线伪标签实验中加 warmup 和余弦衰减的配方（第一轮标签，无扰动，其余与本实验相同）。比较时看第 2000 步及以后 7 个存档的 Val AUC@5 均值。开跑前定的判定标准是：Val 峰值不低于 0.282，且这个均值比对照高 0.01 以上。

**实验结果**

第 2000 步及以后的 Val AUC@5 均值 ± 标准差：

| 标签 | 扰动 | 用哪些对 | 种子 0 | 种子 1 |
|---|---|---|---|---|
| 第一轮（对照） | 无 | 全部 | 0.263 ± 0.002 | |
| 第二轮 | 无 | 全部 | 0.265 ± 0.003 | |
| 第一轮 | 几何 + 光度 | 全部 | 0.267 ± 0.007 | |
| 第二轮 | 几何 + 光度 | 全部 | 0.279 ± 0.002 | 0.277 ± 0.004 |
| 第二轮 | 只有几何 | 全部 | 0.279 ± 0.003 | |
| 第二轮 | 几何 + 光度 | 内点前 50% | 0.285 ± 0.003 | 0.286 ± 0.003 |
| 第二轮 | 几何 + 光度 | 内点前 25% | 0.284 ± 0.002 | |
| 第三轮 | 几何 + 光度 | 全部 | 0.284 ± 0.001 | |
| 第三轮 | 几何 + 光度 | 内点前 50% | 0.289 ± 0.001 | |
| 第四轮 | 几何 + 光度 | 全部 | 0.285 ± 0.003 | |
| 第四轮 | 几何 + 光度 | 内点前 50% | 0.288 ± 0.003 | |

同一配方换种子时，这个均值相差 0.001–0.002，Test 却可以相差 0.013（只用内点前 50% 的两个种子为 0.253 和 0.266）。

训练前核对了扰动与标签的一致性：模型冻结时，细级目标落在细级窗口内的比例，不加扰动为 0.248，加随机扰动为 0.201，与扰动变换后的标签相符。

**实验结论**

Noisy-Student 式迭代有效，但「更好的老师」和「学生侧扰动」必须同时具备：只换老师、只加扰动都不涨，两者一起使 Val 均值提高 0.016，两个种子一致。起作用的是已知的几何扰动，光度扰动没有作用。在此基础上，只用内点前 50% 的对再提高约 0.006，收紧到前 25% 没有更多收益；迭代到第三轮再提高约 0.005，第四轮不再上涨。

最好的配方是第三轮标签、几何和光度扰动、只用内点前 50% 的对，Val 均值 0.289，Test 0.263。

## 实验二：在最好的配方上逐项改动

**实验目的**

实验一最好的配方是第三轮标签、扰动、只用内点前 50% 的对。

本轮在它上面逐项改动，看能否继续提高：学生是否必须从头重训；扰动强度；把标签先平移到图像内容最吻合的位置，给标签带进老师自己没有的整体偏移信息。另补两个种子。

**实验方法**

配方与第一轮相同，每个方法只改一项：

- 从老师接着训：学生从生成第三轮标签的模型出发，而不是从 zero-shot 起点重训。
- 弱扰动：平移 ±6 px、旋转 ±1.5°、缩放 ±1.5%。
- 强扰动：平移 ±24 px、旋转 ±5°、缩放 ±5%。
- 标签平移到 NCC 峰值：把每对的伪标签仿射在小范围内平移到两幅图梯度幅值归一化互相关（NCC）最大的位置；换两个种子。
- 随机种子 1、2。

判定标准同第一轮：比第一轮最好的配方（Val 均值 0.289）高 0.01 以上；同时看 AUC@3 和 SR@3。

**实验结果**

第 2000 步及以后的 Val AUC@5 均值 ± 标准差：

| 方法 | 均值 ± 标准差 |
|---|---|
| 第一轮最好的配方（三个种子） | 0.289 / 0.289 / 0.288 |
| 从老师接着训 | 0.289 ± 0.002 |
| 弱扰动 | 0.287 ± 0.003 |
| 强扰动 | 0.286 ± 0.002 |
| 标签平移到 NCC 峰值（两个种子） | 0.284 / 0.284 |

三个种子的 Test AUC@5 为 0.263、0.262、0.268，均值 0.264。

开跑前在 CPU 上核对过标签平移的前提：在类 RIPE 路线最好的模型上，测试时把预测平移到 NCC 峰值已经不再提高精度；NCC 峰值离真值的中位距离约 1.3 px。

**实验结论**

没有一项达到判定标准，本路线的方法定为第一轮最好的配方，三个种子的结果稳定。

从老师接着训与从头重训没有区别，第一轮推测的「必须从头重训」不成立，需要的只是更好的老师加上学生侧扰动。扰动强度在 ±6 到 ±24 px 之间影响很小。标签平移到 NCC 峰值略差（−0.005，两个种子一致）：NCC 峰值本身离真值约 1.3 px，对这个水平的老师来说，平移引入的误差不比纠正的偏移少。

与类 RIPE 路线相比，两条路线打平：Val 均值 0.289 对 0.287，Test 三个种子的均值 0.264 对 0.267，差别小于同一配方换种子时 Test 的波动。
