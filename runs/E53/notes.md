# 逐级加入细化位置奖励的末次存档对照

本轮保留粗匹配位置奖励及五级细化前向和置信度 BCE。K 控制尺度 16、8、4、2、1 中从粗到细获得位置奖励的级数。使用筛选门槛 0.8、seed 0、EMA 和 7907 次更新。正式论文分层对照见 E55，按验证集选模并关闭置信度 BCE。

## 竖直偏差诊断

对相同 Test 图对，K3、K4 相对 K5 的图心竖直差中位数分别为 −0.843、−1.975 px，方向一致的图对分别为 944/953 和 953/953。偏差在原始匹配中已经可见，限制到置信度最高的四分之一同样存在。在 Val 估计固定平移后对 Test 应用，K3、K4 的诊断 AUC@5 为 29.718%、30.144%。正式成绩使用原始预测。

原生逐层探针使用同一 Val 图对，三组在首个位置细化器前已有偏差差异。单图对证据尚不能定位整个验证集的偏差来源。逐层数值、RANSAC 前的全量核对和原始结果见 [#284](https://github.com/Guochu0-0/moon-exp/issues/284#issuecomment-7011832194)。
