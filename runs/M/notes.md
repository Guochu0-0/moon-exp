本实验把 LoFTR 上两条路线最好的配方搬到 RoMa 底座上。实验分两部分：伪标签路线，以及类 RIPE 路线。

这一组训练的代码是从一份被反复覆盖的代码副本里跑的，确切代码已无法复原，记录中的代码版本是按时间推断的。

## 伪标签路线

**实验目的**

在 LoFTR 上，伪标签路线和类 RIPE 路线都停在 Val AUC@5 0.29 左右。

zero-shot 时最强的是 AnyMatch-RoMa。把同样的方法搬到 RoMa 上，看它在更强的起点上能提高多少。

**实验方法**

起点都是 AnyMatch 发布的 RoMa 多模态权重，SAR 输入用逐 patch 的 min–max 映射（在 zero-shot 的输入映射对比中，这个映射对它最好）。RoMa 的粗级特征来自 DINOv2，始终冻结；细级特征来自 VGG，除注明「训 VGG」的方法外也冻结；其余的解码部分（粗级的全局匹配与各尺度的细化）全部训练。优化器为 AdamW，权重衰减 0.01，学习率前 500 步从 0.1 倍线性升到设定值，之后按余弦曲线降到 0，batch 1。每 1000 步保存权重并在 Val 上评测，取 Val AUC@5 最高的一步作为结果；只有部分方法在这一步上评测了 Test。比较时看第 2000 步及以后各存档的 Val AUC@5 均值。

损失用 RoMa 原本的监督：粗级全局匹配的分类损失、各尺度的 certainty 损失和细化的回归损失，真值由伪标签仿射给出。每一步以 0.5 的概率交换光学和 SAR 的方向（标签取逆）。学生都从 zero-shot 起点重训。未注明时只用内点数前 50% 的对、不加扰动、学习率 1e-5、8000 步。

三种伪标签：LoFTR 伪标签路线的第三轮标签；RoMa zero-shot 起点自己生成的标签；用「LoFTR 第三轮标签，无扰动」第 2000 步的 RoMa 模型重新生成的标签（RoMa 的第二轮）。

各方法：

- LoFTR 第三轮标签：照搬 LoFTR 上最好的配方（加几何和光度扰动）；同配方学习率 3e-6；不加扰动，另换一个种子；不加扰动且用全部对。
- RoMa 第二轮标签：加扰动和不加扰动各一个。
- RoMa 自己的标签：基础方法另换一个种子；学习率 3e-5；训 VGG；训 VGG 且学习率 3e-5，另换两个种子。这几个方法除种子外都在第 8000 步附近取到峰值、曲线仍在上升，所以又补了更长和更激进的训练：训 VGG 训 16000 步；训 VGG 且学习率 3e-5 训 16000 步；不训 VGG、学习率 3e-5 训 16000 步；训 VGG 且学习率 1e-4；训 VGG 且学习率 3e-5 用全部对。
- 最后一个对照：训 VGG 且学习率 3e-5，但换回 LoFTR 第三轮标签。

判定标准同 LoFTR：比参照高 0.01 以上才算有效。

**实验结果**

zero-shot 起点重新评测的 Val AUC@5 为 0.259，Test 为 0.243。

第 2000 步及以后的 Val AUC@5 均值 ± 标准差：

| 标签 | 方法 | 均值 ± 标准差 |
|---|---|---|
| LoFTR 第三轮 | 加扰动 | 0.304 ± 0.001 |
| LoFTR 第三轮 | 加扰动，学习率 3e-6 | 0.297 ± 0.002 |
| LoFTR 第三轮 | 不加扰动（两个种子） | 0.306 / 0.305 |
| LoFTR 第三轮 | 不加扰动，全部对 | 0.306 ± 0.002 |
| RoMa 第二轮 | 加扰动 | 0.304 ± 0.002 |
| RoMa 第二轮 | 不加扰动 | 0.306 ± 0.002 |
| RoMa 自己 | 基础（两个种子） | 0.304 / 0.306 |
| RoMa 自己 | 学习率 3e-5（两个种子） | 0.309 / 0.308 |
| RoMa 自己 | 训 VGG（两个种子） | 0.310 / 0.310 |
| RoMa 自己 | 训 VGG，学习率 3e-5（三个种子） | 0.312 / 0.311 / 0.313 |
| RoMa 自己 | 训 VGG，16000 步 | 0.312 ± 0.003 |
| RoMa 自己 | 训 VGG，学习率 3e-5，16000 步 | 0.308 ± 0.006 |
| RoMa 自己 | 学习率 3e-5，16000 步 | 0.309 ± 0.005 |
| RoMa 自己 | 训 VGG，学习率 1e-4 | 0.309 ± 0.006 |
| RoMa 自己 | 训 VGG，学习率 3e-5，全部对 | 0.305 ± 0.006 |
| LoFTR 第三轮 | 训 VGG，学习率 3e-5 | 0.309 ± 0.002 |

16000 步的训练每 2000 步才评测一次，均值包含第 2000–16000 步的 8 个存档。

在 Test 上评测过的方法：LoFTR 第三轮标签加扰动 0.283、不加扰动 0.278；RoMa 第二轮不加扰动 0.286；RoMa 自己的标签基础方法两个种子 0.276、0.279，学习率 3e-5 为 0.284，训 VGG 为 0.281。

**实验结论**

伪标签在 RoMa 上同样有效：Val 均值从 zero-shot 的 0.259 升到 0.304–0.306，Test 从 0.243 升到 0.276–0.286，比 LoFTR 上两条路线最好的结果（Test 约 0.265）还高约 0.015。

提升与老师无关：用 LoFTR 的标签、RoMa 自己的标签、RoMa 重新生成的第二轮标签，结果都在 0.304–0.306。扰动、筛选、迭代、换种子的影响也都在 ±0.002 以内。这与 LoFTR 上必须有更好的老师和学生侧扰动才涨不同。RoMa 自己的标签不依赖任何外部模型，是最干净的无标注自训练。

训 VGG、提高到 3e-5 学习率各带来约 0.004–0.005，两者一起时三个种子的均值约 0.312，比基础方法高约 0.007，没有达到 0.01 的标准。训练更长、学习率更高、用全部对都没有进一步提高。

## 类 RIPE 路线

**实验目的**

LoFTR 上类 RIPE 路线最好的配方是粗级 ±1 期望、外点扣分 −0.25、负样本对。RoMa 的结构与 LoFTR 不同：它不靠阈值筛选匹配，而是给每个像素一个对应位置和一个 certainty（这个位置有多可信）。本部分看这个配方在 RoMa 上怎么落地、是否塌缩、能提高多少。

**实验方法**

每一步按 certainty 从当前模型的稠密对应中抽 5000 个点，用 RANSAC（3 px）估出仿射；每个像素的对应落在这个仿射 3 px 以内记 +1，否则记外点扣分。负样本对（SAR 取自其他区域）上，落在仿射 3 px 以内的像素记 −1，其余记 0。损失有两项：

- 锚点项：粗级全局匹配在每个粗网格上选中的锚点概率，乘以该网格内像素分数的均值，取负；
- 取舍项：各尺度 certainty 经 sigmoid 后乘以像素分数，取负，相当于让模型在内点处更自信、外点处更不自信。

基础配方是两项都用、外点扣分 −0.25、加负样本对、学习率 1e-5、4000 步，与 LoFTR 上的对应。各方法：

- 基础配方；取舍项权重降到 0.1；学习率降到 1e-6；
- 只留锚点项，不训 certainty；
- 取舍项里外点记 0（锚点项仍为 −0.25）；
- 只给正分：外点记 0，不用负样本对。

基础配方、只留锚点项、只给正分各配一个随机 reward 对照：分数在像素之间随机打乱。

**实验结果**

各存档的 Val AUC@5：

| 方法 | 1000 | 2000 | 3000 | 4000 |
|---|---|---|---|---|
| 基础配方 | 0.000 | 0.000 | 0.000 | 0.000 |
| 基础配方，随机对照 | 0.000 | 0.000 | 0.000 | 0.000 |
| 取舍项权重 0.1 | 0.063 | 0.000 | 0.001 | 0.000 |
| 学习率 1e-6 | 0.222 | 0.071 | 0.039 | 0.033 |
| 只留锚点项 | 0.267 | 0.250 | 0.264 | 0.260 |
| 只留锚点项，随机对照 | 0.258 | 0.224 | 0.213 | 0.210 |
| 取舍项外点记 0 | 0.250 | 0.211 | 0.256 | 0.254 |
| 只给正分 | 0.208 | 0.078 | 0.037 | 0.039 |
| 只给正分，随机对照 | 0.217 | 0.116 | 0.087 | 0.059 |

基础配方、它的随机对照和取舍项权重 0.1 都在 450 步内塌缩：certainty 全部被压到 0，抽点退化为随机，对应场也被拖坏。

**实验结论**

类 RIPE 的配方在 RoMa 上没有提升。

基础配方的随机对照同样塌缩，说明塌缩来自优化过程本身，而不是分数的内容：外点扣负分时，「certainty 全为 0」是一个出不来的状态；细化的位移与 certainty 共用特征，没有回归项锚住时一起被拖坏。推测根本原因是 LoFTR 可以靠阈值让外点消失，RoMa 必须给每个像素一个对应，在线打分在 RoMa 的结构上没有合适的作用点，未经验证。
