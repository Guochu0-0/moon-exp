## 假设

在 S1 之上加细级 RL：以 soft-argmax 为均值的高斯策略，整对 reward（warp 后跨模态结构相似度）+ 可选逐匹配残差 reward，组内 baseline，能超过 S1。

## 改动

finetune/rl.py。策略协方差 σ_i² I + σ_g² 11ᵀ（σ_i 0.1、σ_g 0.25，归一化窗口坐标），K 4，reward 默认梯度幅值 NCC。
默认与离线伪标签项（S1 的损失）同时训练，全部模块，lr 1e-5，从 S1 step 6000 出发 4000 步。
各方法：pair = 整对 RL；pair_match = 再加逐匹配；match = 只逐匹配；pair_x4 = 整对权重 4；sigg05 = σ_g 0.5；
cfog = CFOG reward；K8；l2sp = 加 L2-SP；l2sp_pure = 去掉伪标签项 + L2-SP；from_b0 = 从 zero-shot 出发；
small_sigma = σ_g 0.1 / σ_i 0.05；fine_only = 纯 RL 只训细级；fine_accum = 纯 RL 只训细级 + 梯度累积 16；pair_x4_accum = 伪标签 + 整对 ×4 + 累积 16。
每个方法取 Val AUC@5 最好的 ckpt。

## 结论

全部与不加 RL 的对照（S1c，Val AUC@5 0.260–0.268）无法区分：各方法最好 ckpt 的 Val AUC@5 在 0.264–0.273。
l2sp_pure 前期退化（step 1000 为 0.215），L2-SP 把参数拉回后恢复到 0.269。
固定 Val pair 上策略均值处的整对 reward 没有上升（S1 0.1002，pair 0.0998，pair_x4 0.0994）。
不带伪标签项、训练全部模块的纯 RL 在 1000 步内塌缩（匹配数 → 0，Val AUC@5 → 0；未收录）。
原因（事后推导）：整对 reward 几乎只取决于共享平移 z，而 Σ⁻¹(a − μ) 中共享部分每个匹配只有 z/(Mσ_g²)，
独立噪声部分 ε/σ_i² 主导梯度却几乎不影响整对 reward。另 σ_i = 0 时 Sherman–Morrison 0/0 得 NaN（K16 那组）。
