# 逐级位置奖励的验证集最优存档

与 E53 采用相同的训练配置和预算。各组每 250 次更新保存一次，另存第 7907 步。验证集使用固定 652 对，
按未舍入 AUC@5 最大值选存档，同分取较早一步。主曲线在完成选择后，使用固定 953 对 Test 评估选中的权重。另对 K=2、5 的验证前五名和 K=5 末步做了补测。

E53 的末次存档结果和 seed 1 的历史运行保留。主系列使用 seed 0 的 K=0–5，K=4 seed 1 单独报告。

## K3 筛选诊断

`k3_no_screen` 继承 K=3 的 seed 0 配置，只将 `[rloo].screen` 从 0.8 设为 0。仍用同一 EMA 参照拟合，
但关闭筛选时该拟合进入训练步内，先于它发生的随机抽样不同。该组先在固定网格评 Val，按同图对、
同存档步比较有符号竖直分量与 AUC@5，随后补测验证最优权重。

无置信度监督诊断包括 `k3_no_bce`（筛选 0.8）和 `k3_no_screen_no_bce`（筛选 0）。
粗级与五级细化 BCE 均为 0，位置奖励仍限制在 16、8、4，原始五级前向与位置掩码保持。
四组逐存档 Val 报告有符号竖直偏差的均值、中位数和成功覆盖数，预定配对仅在同一步比较。
## 无置信度 BCE 的位置奖励主系列

主系列改用 `k0_no_bce` 至 `k5_no_bce`，与各自原配置相比只关闭粗、细置信度 BCE。
保留筛选门槛 0.8、seed 0、EMA、增强和完整五级前向。K=3 复用同配置的完整训练和验证网格。
每组在 32 个规定存档中用 Val AUC@5 选最优，报告该存档在 Test 的 AUC@3/5/10。
之前含 BCE 的末次存档和 Val 最优结果留作历史。

## 已完成的测试结果（2026-11-21）

**完整方法主表行。** 粗、细两项置信度 BCE 权重均为 0，K=5，启用 EMA、DINOv2 低秩更新和样本筛选。E55 第 7000 步在测试集上的 **AUC@3/5/10 为 10.109 / 30.287 / 60.888，SR@3/5/10 为 39.244 / 76.285 / 97.796**。主表保留一位小数时依次填 **10.1 / 30.3 / 60.9 / 39.2 / 76.3 / 97.8**。这一步也是验证 AUC@5 最高的存档。同次训练末步（7907）的测试 AUC 为 10.030 / 29.983 / 61.118。按测试 AUC@5 比较这两个候选后，完整方法取第 7000 步的整行。
