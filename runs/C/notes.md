## 假设

按 RIPE++ 匹配器的写法，在 AnyMatch-LoFTR 粗级 dual-softmax 上做闭式期望 loss = −Σ P(i,j)·r(i,j)：
r 取当前模型仿射 RANSAC（3 px）的内点 +1、外点 −1。从 zero-shot 出发单独训练，看它会不会像 S2 那样塌到 [I|0]；
塌的话加什么能防住（「【类 RIPE】粗级闭式期望从 zero-shot 单独训练：是否塌缩」#49，建议顺序见 #48）。

## 改动

finetune/coarse.py。只对本步推理同款的粗匹配（阈值 + MNN）给分，其余格不监督；RANSAC 失败的对全给 −1；
按粗格数 L 常数归一化。不加细级、不加伪标签。AdamW lr 1e-5 恒定、bs 1、3000 步（同 S2），全部模块，模块保持 eval。
- C1：无约束。C1p：同配方，r 在同一对的匹配之间随机打乱（随机 reward 对照）。
- C2：每对再配一个负样本对（SAR 取自其他 ROI，并入同一次前向），负样本对上的 RANSAC 内点给 −1、外点 0。C2p：C2 的随机 reward 对照。
每 500 步、另在 10/25/50/100/250 步存 ckpt，逐 ckpt 在 Val 上评测，并在 200 个 Val 负样本对上监控（finetune/negpairs.py）。
选模按 Val AUC@5 峰值。队列与汇总：scripts/finetune/ripe49.py、collapse.py、trainlog.py。

## 结论

**不塌缩到恒等。** 3000 步内，C1、C2 估出的仿射相对 [I|0] 的角点位移一直约 25 px（与 zero-shot 相同；真值带几十 px 平移），
逐对误差与恒等变换误差相差 < 1 px 的对占 2–3%（zero-shot 3%）。对照 S2：负样本对上 5776 个匹配全是恒等内点，conf[i,i] 0.75–0.99。

| | Val AUC@5 | Val SR@3 / @10 | Test AUC@5 | Test SR@3 / @10 |
|---|---|---|---|---|
| zero-shot（B0） | 0.220 | 0.293 / 0.853 | 0.188 | 0.249 / 0.732 |
| S1（离线伪标签） | 0.272 | 0.339 / 0.943 | 0.233 | 0.297 / 0.885 |
| C1 step 1500 | 0.281（CI 0.262–0.298） | 0.367 / 0.956 | 0.256（CI 0.241–0.271） | 0.341 / 0.908 |
| C2 step 500 | 0.285（CI 0.266–0.302） | 0.379 / 0.939 | 0.259（CI 0.244–0.275） | 0.345 / 0.871 |

观察：
- **起步即塌到「无匹配」。** 四组都在 10–100 步内掉到几乎 0 匹配（Val 上 C1 step 50 有 492/652 对匹配 < 3）。
  zero-shot 在 Train 上内点率低（冒烟测试前几步 7–45%），外点的 −1 占多数，P 整体被压到粗匹配阈值以下。随机 reward 对照同样掉下去，所以这一步与自洽无关。
- **真 reward 能恢复，随机 reward 不能。** C1、C2 在 250–500 步回到上千匹配、内点率 45–60%，并超过 zero-shot；
  C1p、C2p 停在 0 匹配（无匹配 → 无梯度，是吸收态）。增益来自内点信号，不是训练扰动。
- **有向恒等的漂移，但自己回落。** C1 负样本对上的恒等匹配数（中位数）：zero-shot 3 → step 2000 44 → step 3000 11；
  正样本对的 conf[i,i] 均值 0.001 → 0.009 → 0.006。C2（负样本对）峰值更低：29、0.0057。负样本对压住了漂移，但 AUC 上看不出差别。
- 平台期（step ≥ 1000）Val AUC@5 0.26–0.28，与 S1 的平台期（0.26–0.27）相近；Test 上两者都高于 S1（0.256 / 0.259 vs 0.233）。

|---|---|---|---|

S2 的塌缩是与内容无关的位置捷径（#48 的推断成立）；zero-shot 起点不偏向恒等。
