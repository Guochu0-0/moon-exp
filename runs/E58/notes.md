# 完整 K5 的合并 AUC@5 为 31.02%，比同归一化的公开权重高 5.96 个百分点

**摘要**

在原 Val 和 Test 的 1,605 对人工标注上，按各训练方法的末步存档重新评分。完整 K5 的合并 AUC@5 在 28 个可评方法里最高，领先同归一化的 AnyMatch RoMa 公开权重 5.96 个百分点。K4 的 SR@10 最高，SCENES 的 AUC@3 最高。去 EMA 保留为历史训练失败行。

**引言**

此前同一批月球光学与 SAR 配准方法分开在原 Val 和 Test 上报告。部分训练方法还用 Val 峰值存档做过 Test，因此已有逐对结果对应的训练时刻并不一致。本次把方法固定在训练终点，再用两份原 split 的全部人工标注合并计分。

**方法**

*数据和评分。* 原 Val 的 652 对和原 Test 的 953 对各自读取和保存预测。两份原 split 覆盖 13 个 ROI 和 1,955 对影像，量化结果使用其中 1,605 对有人工标注的 patch。每对影像的误差是光学检查点经过预测仿射后到对应 SAR 检查点的平均距离，单位是原始像素。配准失败的误差计为无穷。两份 split 的逐对误差以完整浮点精度合并，所有 patch 对等权。AUC@T 是 [0,T] 内误差累积曲线的归一化面积，SR@T 是误差不超过 T 的比例。

*方法和权重。* 未配准对照与其他公开基线沿用 B0 的推理配置。GDROS 使用公开 OS 权重和最小二乘仿射。AnyMatch RoMa 公开权重对照取 B0m 的 `anymatch_roma__minmax`，光学除以 255，SAR 按 patch 做 minmax，与微调方法的推理配置一致。其余匹配结果沿用原 3 px RANSAC 仿射。完整配置与奖励层级消融使用 E55 种子 0 的训练末步，冻结 DINOv2 与关闭样本筛选使用 E56 的训练末步，SCENES 使用 E50 的训练末步。完整 K5 只评一次。

*已有结果核验。* 逐 split 核对历史配置、权重身份、拟合方式与当前标注清单，补齐旧选模存档没有覆盖的末步 Test。XoFTR 与 MINIMA-XoFTR 的历史上游代码带未提交改动标记，在固定上游提交上重跑两份 split。RIFT2 Val 以及历史出现非有限仿射的三份 split 用原始点对重新拟合。实际成功更新数从训练日志核对，保留原配置实际到达的训练终点。

**结果**

*完整 K5 的合并 AUC@5 和 AUC@10 最高。* 公开基线中，采用相同输入归一化的 AnyMatch RoMa 在这两个指标上最高。完整 K5 在相同的 1,605 对标注上把 AUC@5 提高到 31.02%，AUC@10 提高到 62.13%。冻结 DINOv2 和关闭样本筛选后的 AUC@5 都更低。奖励层级中，K2 的 AUC@5 低于 K1，K3 至 K5 逐级升高。SCENES 的 AUC@3 略高于完整 K5，K4 的 SR@10 比完整 K5 高 0.25 个百分点。

**讨论**

这次合并评分固定了训练终点，也统一了公开 AnyMatch RoMa 对照与微调方法的输入归一化。完整 K5 在这批标注上的 AUC@5 和 AUC@10 居首，较紧的 AUC@3 和较宽的 SR@10 则由其他配置领先。每个训练配置使用其既有种子，表中差值描述的是这批标注上的观测结果。
