# zero-shot RoMa 的粗级锚点分布很平，按原分布抽样几乎从不落在概率最大的锚点上

**摘要**

我们准备在 RoMa 上做强化学习：把粗级每个格子对 4096 个候选锚点的打分当作一个概率分布，从中抽样，按 reward 用策略梯度更新。这条路线能不能学，先取决于两件事：这个分布是否尖到抽样总落在同一个锚点上、因而没有探索；策略梯度能回传到哪些模块。我们在 200 对训练影像上检查了 zero-shot 模型。分布不尖，反而很平：按原分布抽样，96% 的格子抽到的不是概率最大的锚点，平均离它约 51 px；经过逐级细化，最终的稠密对应场与不抽样时相差约 21 px，按它拟合出的仿射与不抽样时相差约 41 px，两种 reward 都比不抽样时低。把分布降温到 0.3 以下，抽样仍有 67–79% 落在别的锚点上，但 reward 的均值与不抽样时基本相同。梯度方面，粗级抽样的 log 概率能回传到 DINOv2 的低秩适配器，最细一级加高斯噪声则不能，这与我们此前根据代码结构做的推断一致。粗级抽样不缺探索；需要考虑的是按原分布抽到的样本是否离得太远。

**引言**

RoMa 先在粗级为每个格子从 64×64 个候选锚点中选出目标图上的落点，再逐级细化成逐像素的对应场。推理时，每格取概率最大的锚点（下称 mode），并用它和上下左右 4 个邻居锚点的概率做加权平均。粗级的打分本身就是一个类别分布，所以强化学习可以直接从中抽样：每格抽一个锚点代替 mode，其余照推理跑，再按 reward 提高好样本的概率。

这条路线有两个前提没有检查过。第一，分布如果很尖，抽样几乎总落在 mode 上，同一对影像的多份样本彼此相同，组内比较就没有信号。第二，RoMa 在各级之间切断了梯度，策略梯度能回到哪些模块要由代码结构决定；我们此前只根据代码推断：最细一级上的噪声，其梯度到不了 DINOv2 的低秩适配器。

本文在训练用的扰动下量出 zero-shot 模型粗级分布的尖锐程度，比较不同采样温度下样本与 mode 之间的差距，并用反传确认梯度路径。

**方法**

*模型与数据。* 模型为 AnyMatch 发布的 RoMa 权重，DINOv2 每个块的 qkv 层挂秩 8 的低秩适配器（初值为零，前向与原模型相同）。从 Train 的 7907 对中均匀取 200 对，按训练时的扰动处理：SAR 一侧施加随机仿射（平移在半径 128 px 的圆盘内，旋转 ±20°，缩放 ±20%），再随机擦除 1–3 块，不加光度扰动。

*抽样。* 输入为 560²，粗级为 40×40 格。每格按 softmax(打分 / T) 独立抽一个锚点，把 mode 换成它，其余照推理算出粗级对应，再照推理逐级细化（这一部分我们重写了一遍，取 mode 时与原前向的最细一级对应场逐像素相差的中位数为 0.03–0.09 px，99% 分位不超过 1.04 px）。每对每个温度抽 16 份，温度 T 取 1、0.5、0.3、0.2、0.1；T = 1 即原分布。

*量。* 每格的熵（以 e 为底；在 4096 个锚点上均匀为 8.32）与 mode 的概率；抽到非 mode 的比例；抽到的锚点与 mode 锚点的距离；最终对应场与 mode 那份逐像素的差；仿射的差，即两份对应场各自按推理口径抽 5000 个点、RANSAC（3 px）拟合仿射后，patch 四角的平均距离。距离都换算成原始 512 网格上的像素。两种 reward 都只用影像和样本自身：分级残差 reward 是每个像素到本份仿射的残差 r 代入 max(0, 1 − (r/3)²) 后的平均；灰度 NCC reward 是用本份仿射把 SAR 拉到光学网格后两图在重叠区上的灰度归一化互相关。最细一级 certainty 在格内平均大于 0.5 的格子记为可信格，占全部格子的 28%。

*梯度路径。* 在 2 对上分别反传两种 log 概率，记录各模块参数的梯度范数：粗级抽样的 log 概率；以及在某一级输出的对应场上加 1 px 固定方差高斯噪声时的 log 概率，逐级各做一次。低秩适配器的第二个矩阵初值为零，第一个矩阵的梯度因此恒为零，所以只看第二个矩阵。

**结果**

*粗级锚点分布很平，可信格里也是如此。* 全部格子熵的中位数为 5.39，相当于概率平摊在约 220 个锚点上；mode 概率的中位数只有 0.027。可信格稍尖，熵的中位数为 4.52，mode 概率为 0.056，仍相当于约 90 个锚点。只有十分之一的格子 mode 概率超过 0.095。

*按原分布抽样几乎总离开 mode，细化之后整个对应场都变了。* 温度为 1 时，96% 的格子抽到的不是 mode，抽到的锚点平均离 mode 51 px（表 1）。细化收不回这么大的偏离：最终对应场与 mode 那份逐像素相差的中位数为 20.7 px，88% 的像素相差超过 3 px；拟合出的仿射与 mode 那份相差的中位数为 41 px。样本的质量也随之下降：分级残差 reward 从 mode 的 0.129 降到 0.083，灰度 NCC reward 从 0.200 降到 0.173。

*降温后样本仍有变化，reward 的均值与 mode 持平。* 温度降到 0.3 时，79% 的格子仍抽到别的锚点，但对应场与 mode 的差降到 7.1 px，分级残差 reward 为 0.125、灰度 NCC reward 为 0.193，与 mode 相差不到 0.01。温度再降，样本更接近 mode，reward 的均值几乎不变。组内 16 份样本之间整对 reward 的标准差在各温度下相近：分级残差约 0.010–0.012，灰度 NCC 约 0.027–0.035。即使温度为 0.1，仿射之间仍差 16 px，这说明在大扰动下 zero-shot 模型拟合出的仿射本身就不稳定。

**讨论**

粗级抽样不缺探索。我们原先担心分布太尖、抽样总落在 mode 上；实际情况正相反，按原分布抽样时几乎每个格子都离开了 mode，同一对影像的 16 份样本彼此差别很大。策略梯度也确实能沿粗级回到 DINOv2 的低秩适配器；细化层和 VGG 收不到梯度，所以只在粗级抽样时，训练实际改动的只有粗级部分。

需要权衡的是样本离得太远。温度为 1 时，样本的对应场与 mode 平均差约 21 px，reward 明显低于 mode，组内比较的大多是比推理输出差得多的样本；把这些远处样本的概率压下去，未必能让 mode 本身变准。降温到 0.3 左右，样本仍有足够的变化，reward 的均值与 mode 持平，比较的对象更接近推理时的输出。温度只是采样的超参数，推理仍取 mode，不受影响。

本检查只看 zero-shot 模型，训练开始后分布可能变尖或变平。组内 reward 的标准差在各温度下相近，所以降温不会让 reward 之间的差别消失；但它没有说明这些差别有多少来自所抽的锚点、多少来自 RANSAC 本身的不稳定。温度为 0.1 时仿射之间仍差 16 px，提示后者不小。按原分布抽样的首批训练正在进行；它与降温后的抽样相比学得如何，值得作为下一步检验。
