## 结论速览

1. **原报告的核心解释在 LoFTR 上部分成立，在 RoMa 上不成立。** LoFTR 上「更好的老师 + 学生侧扰动」一起才涨（P：+0.016），和原报告第 2 条一致；但「学生必须从头重训」不成立（P 实验二：从老师接着训结果相同）。RoMa 上换老师、扰动、筛选、迭代全部平坦（±0.002，M），说明 RoMa 的平台**不是**老师–学生耦合造成的【推断】。
2. **RoMa 学生对标签质量不敏感。** 用 zero-shot 自己的标签（老师 Val 0.259）和用 LoFTR 第三轮标签（老师 Val 约 0.29），学生都停在 0.304–0.306。【推断】在这个区间里，标签精度不是 RoMa 的瓶颈；原报告第 4 节「伪标签质量就是上限」对 RoMa 不适用。
3. **RoMa 无标注训练已接近「有标注、没见过该区域」的水平。** M 最好的配方 Val 均值约 0.312、Test 0.276–0.286；E2 用真标注、在另一集合上训练的 RoMa 为 Val 0.319、Test 0.272。E1 在评测集上过拟合能到 0.347 且还在涨。【推断】剩下的差距更像「跨区域泛化」和「网络哪部分能动」的问题，而不是标签问题。
4. **RoMa 上唯一带来增益的是「让特征端能动」**：训 VGG、提高学习率各 +0.004–0.005。新文献在这一点上一致：WeSTAR（2511.14238 表 5）在深度基础模型的自训练中发现只训解码器没有增益、增益来自编码器（LoRA）；Surgical fine-tuning（2210.11466 图 2）发现输入端的分布偏移最适合调前几层；UniMatch V2（2410.10777 表 7）38 个设置中 37 个微调 DINOv2 好于冻结。DINOv2 在 M 中始终冻结，用 LoRA 训练后合并，推理不变慢。
5. **新候选按成本分四档**（第 3 节）：①零训练，只合并或重估权重（多种子权重平均、WiSE-FT、在 Train 上重估 BN 统计）；②和一次 M 训练同成本，只改损失或训练参数（权重 EMA、粗级软目标、细化回归的鲁棒损失、可训模块与分模块学习率、锚回 zero-shot 的正则、特征层 dropout、遮挡类扰动）；③1–2 倍成本（训练推理时才用的 864 上采样那一遍、稠密自标签、WarpC 损失）；④2 倍以上（DINOv2 LoRA、DINOv2 自监督续训）。
6. **原报告没覆盖的稠密匹配器自监督方向**：WarpC（2104.03308）证明 W-bipath + 合成 warp 监督在无标注下优于稀疏真值监督（表 3），并给出两种会退化的一致性约束（表 1）；SMURF（2105.07014 表 6）显示用模型自己在干净输入上的最终输出监督扰动输入、且不加前后向掩码最好；PWarpC（2203.04279 表 2）显示最小化代价体熵的损失效果差。对 RoMa 做无标注微调的公开工作仍【未找到】（检索截至 2026-10-06），iMatching（2312.02141）的 DKM 是最近的先例，但依赖视频和 BA，不适用于单对仿射。
7. **已在 RoMa 上试过的做法单列在第 4 节**：换老师、学生侧几何 + 光度扰动、内点前 50% 筛选、第二轮标签、更长训练、更高学习率、类 RIPE 在线打分。这些不再列入候选。

### 1.1 结论速览逐条

### 1.2 第 3 节「什么让多轮继续涨、什么让它停住」

- 「学生看到的比老师难」：LoFTR 成立，RoMa 不成立。
- 「学生不从老师权重续训」：LoFTR 上不需要；原报告自己也注明「重初始化不是普遍必要的」，现在有了直接反例。
- 「集合逐轮扩大」：没有按课程试过，只试过固定比例筛选。
- 「老师误差和学生不同源」：RoMa 上用 LoFTR 标签（不同源）与用自己的标签（同源）打平。
- 「对照 S1r2：学生 ≈ 老师，停在不动点」：对 RoMa 第一轮不成立（学生明显超过老师）；对第二轮，「RoMa 第二轮标签」与第一轮打平，形式上像不动点，但换成别的老师也打平，所以不动点不是原因【推断】。

**修正后的看法**【推断】：RoMa 的增益主要来自「解码器适应本数据和仿射式的对应关系」，几百步内完成，和标签精度在 0.26–0.29 范围内的差别无关。之后能动它的，只有改变「网络哪部分可以学」（训 VGG）和「学多快」（学习率）。E2 显示真标注也只到 0.319，这一水平更像跨区域泛化的限制。所以下一步的候选应当偏向：特征端的适应、提高跨区域泛化的权重平均与正则、训练与推理口径对齐，以及能带入仿射标签之外信息的无标注损失；而不是继续调标签。

补充说明（都是【推断】）：
- **R1、R2 的选模**：权重混合和 α 的选择用 Val，与现在用 Val 选存档同一口径，不涉及用 Val 训练。若要完全不用标注，可用 Q 的「内点数 ≥ 200 的对的比例」。
- **R1 的风险**：原文提到学习率高时模型之间可能有误差壁垒，均匀平均会变差。M 中学习率 3e-5 的三个种子同起点、同配方，属于原文中均匀平均有效的那一类，但没有验证。
- **R12 的约束问题**：warp 监督那一项用的是 Train 影像自身的合成变换（同模态对），没有引入新影像，但是否算「扩充训练数据」需要用户定。只用 W-bipath 一项则不涉及。另外，W-bipath 对「光学→SAR 偏 +b、SAR→光学偏 −b」这种成对的偏移，两条路径的偏移正好抵消，看不见；它看得见的是网络整体的常数偏置（原文 §3.4 的分析）。
- **R13 与 M 的关系**：M 证明「换一个仿射老师」不起作用；R13 换的是标签的形式（稠密 vs 整对仿射），信息不同，所以不和 M 的结论冲突。风险是老师的局部错误被直接复制，变体中的掩码就是为此设的。
- **R14、R15 的前提**：WeSTAR、UniMatch V2、SEAR 的任务分别是单目深度、分割、多视图重建，都不是跨模态匹配；SEAR 恰好把 LoRA 加在跨视图模块、DINOv2 冻结，和「加在 DINOv2 上」并不相同。
- **全部候选都不针对**原报告结论第 5 条的系统偏差。
