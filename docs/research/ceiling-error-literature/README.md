# 带噪真值下的评测上限：#62 做法的文献核对（#67）

> 被核对的对象：`round2-51-53` 分支 `runs/Q/notes.md`「评测上限（#62）」，以及 `scripts/finetune/ceiling_mc.py`、`ceiling_gp.py`。
> 来源编号见 [sources.md](sources.md)，那里注明了每条是只核了元数据，还是也读了原文。调研日期 2026-09-30。

## 结论

- **#62 没有能整体引用的出处。** 它是把几块标准结果自己组合起来的：线性回归的帽子矩阵 / 残差理论、配准里的 FLE–FRE–TRE 理论、高斯过程误差场，再加参数化 Monte Carlo。每一块都有教科书级或经典论文出处，但把它们拼成「带噪检查点下的理想仿射上限」这一整套流程，文献里没找到先例。论文里应写成「我们提出的估计流程」，并逐块引用。
- **核心推导站得住。** e = (I−H)f + ε 与 r + Hε′ 同分布，靠的是正态下 Hε 与 (I−H)ε 相互独立。这是线性模型的标准结果（SL03），在配准文献里对应「FRE 与 TRE 不相关」（F09）。对仿射这种线性模型，这个结论是精确的，不需要一阶近似。
- **最不标准的是第 3 项。** 高斯过程的相关长度 ℓ 用「留一 / 全点 RSS 之比」去匹配，幅度逐对做矩匹配，这两步都不是文献里的标准做法。标准做法是边际似然、留一预测似然（RW06 §5.4），或者拟合经验变差函数（C85、C93）。不过 #62 已经扫过 ℓ = 16–512，AUC@5 只在 0.365–0.385 之间变，换成标准方法定 ℓ，结果大概率还落在这个区间里。
- **主结论（Val AUC@5 上限约 0.38）不太会被推翻**，量级可以保留。但有两处要复核或改说法：
  1. **白场下界和 GP 小 ℓ 端对不上。** ℓ = 16 时，错位场在检查点之间已经基本不相关，按理应接近「错位场互不相关」的那一行（0.282），实际却是 0.365。两个脚本里都没有产出 0.282 那一行的代码，需要查清它是怎么算的，再决定下界该写多少（见第 3 项）。
  2. **「上限」一词不严格。** 主估计是「对整片 L2 最优的仿射」按协议打出的期望分数，不是严格上界：某一对上，别的仿射完全可能在检查点上得分更高（检查点最小二乘的 0.43 就高于它）。论文里建议叫「理想仿射参考水平」（oracle-affine reference），并把 0.43 和 0.28 作为两侧的敏感性区间一起报。
- **σ ≈ 1 px 是识别假设，不是测出来的。** 只靠单次标注的残差，分不开标注噪声和错位场。#62 靠「y 向没有错位场」这个假设来定 σ，而 y 向每自由度残差均值 1.7、中位 1.3 px²，所以 σ_y 最高可能到约 1.3 px。标准做法是重复标注，直接测定位误差（C09、M11）。

| 3a | 错位场建模为零均值平稳高斯过程，平方指数核 | 核：RW06 §4.2 式 (4.9)。空间误差场按随机场 / 克里金建模：M63、C93 | 可用，但核的选择偏光滑 | S99 明确指出平方指数核对物理场过于光滑，推荐 Matérn。影响应该不大：ℓ 从 16 扫到 512，结果只变 0.02。可以补一组 Matérn ν = 3/2 作敏感性 |

## 结论会不会变

| 结论 | 判断 |
|---|---|
| Val AUC@5 上限约 0.38（Test 0.37） | 大概率不变。定 ℓ 的方法和核形状的影响都在 ℓ 扫描已覆盖的约 ±0.02 以内；σ 取到 1.3 时要补跑确认 |
| 两侧边界 0.43 / 0.28 | 0.43 站得住（偏乐观的方向有理论依据）；**0.28 要先弄清怎么算的**，再决定能不能叫下界 |
| 「留一法 0.209 作废」 | 站得住（A74、E04：留一法偏悲观） |
| 「卡住上限的是 x 向错位场」 | 站得住。它依赖 σ ≈ 1 的假设，但 x 每自由度 19.8 px² 远大于任何合理的 σ² |
| Q4 / P8 达到上限的约 76% / 72% | 随 0.38 一起基本不变 |
| 只有标注噪声时 AUC@5 约 0.75 | 对 σ 敏感，应报 σ ∈ [0.8, 1.3] 的区间 |

## 论文里的建议写法

- 用词：用「理想仿射参考水平 / oracle-affine reference level」或「噪声上限（noise ceiling）」，不说「upper bound」，并明确它是模型化的期望分数。
- 方法段按块引用：
  - 残差分解和留一偏差：SL03、A74、E04；
  - 由残差估计定位误差：F98；
  - 残差与目标误差独立：F09；
  - 检查点误差如何进入报告精度：ASPRS23 §7.11–7.12；
  - 误差场模型：RW06（写明是平方指数核），如果补做了 Matérn，加引 S99；
  - 概念：N14 / LC19，以及 C09（观察者变异作参照）。
- 明确写出三条假设：标注误差独立同分布、各向同性、正态；错位场为平稳高斯过程、幅度逐对估计；σ 由 y 向残差定。然后给 σ 与 ℓ 的敏感性表。
- 最有说服力的补强：抽一小部分检查点重复标注（同一人隔天重标，或两人各标一遍），直接测 σ。这是配准文献里的标准做法（C09、M11），可以替掉第 2 项的识别假设。
