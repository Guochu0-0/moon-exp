**实验目的**

上一个实验把 Val 和 Test 的标注合在一起训练，再在同样的集合上评测，回答的是网络在见过答案时最多能做到多少。这里换一个问题：用真实标注监督，但评测时不让模型见过评测集，能做到多少。它是无标注方法最直接的对照：如果有标注的训练在没见过的区域上也只到同样的水平，说明无标注方法与有监督之间已经没有多少差距。Val 和 Test 的区域互不重叠，所以这同时是跨区域的泛化测试。

**实验方法**

做法与上一个实验相同，只是每个方法只在一个集合上训练：在 Test 上训练的方法看它在 Val 上的结果，在 Val 上训练的方法看它在 Test 上的结果。标签同样是每对全部标注点最小二乘拟合的仿射，训练中不变，不加扰动。底座取上一个实验里较好的设置：

- LoFTR：起点是 AnyMatch 发布的 LoFTR 多模态权重，损失与 LoFTR 原文相同，学习率 5e-5，共 8000 步。
- RoMa：起点是 AnyMatch 发布的 RoMa 多模态权重（输入按最小-最大值归一化），损失与 RoMa 原文相同，训练解码器和 VGG 特征，学习率 1e-5，共 12000 步。

优化器 AdamW，500 步线性 warmup 后余弦衰减，batch 1。训练集为 Test 953 对或 Val 652 对。为了不让评测集参与选模，一律取最后一步作为正式结果，步数在开跑前定好，依据是上一个实验里 LoFTR 在 8000 步内已经平稳、RoMa 到 12000 步只剩很小的上涨。节点页上每个方法在它自己训练集上的分数是训练集上的分数，不算泛化结果。

**实验结果**

逐存档的 Val AUC@5（在 Test 上训练的方法，这是没见过的集合；在 Val 上训练的方法，这是训练集）：

| 步数 | LoFTR，Test 上训练 | LoFTR，Val 上训练 | RoMa，Test 上训练 | RoMa，Val 上训练 |
|---|---|---|---|---|
| 0 | 0.219 | 0.219 | — | — |
| 2000 | 0.269 | 0.278 | 0.313 | 0.323 |
| 4000 | 0.275 | 0.298 | 0.308 | 0.338 |
| 6000 | 0.268 | 0.304 | 0.322 | 0.349 |
| 8000 | 0.267 | 0.300 | 0.321 | 0.354 |
| 12000 | — | — | 0.319 | 0.360 |

在没见过的集合上，两个在 Test 上训练的方法到第 2000 步已接近最终水平，之后在 ±0.01 内波动；在 Val 上训练的方法在自己的训练集上则持续上涨。

与其他实验对比（AUC@5，「没见过」指本实验在另一集合上训练的结果，「见过」指上一个实验在 Val 和 Test 上一起训练的结果）：

| | Val | Test |
|---|---|---|
| AnyMatch-LoFTR zero-shot | 0.220 | 0.188 |
| LoFTR，有标注，没见过 | 0.267 | 0.238 |
| LoFTR，有标注，见过 | 0.305 | 0.296 |
| 无标注：在线打分训练（另加负样本对） | 0.292 | 0.266 |
| 无标注：离线伪标签迭代第三轮 | 0.290 | 0.263 |
| AnyMatch-RoMa zero-shot | 0.262 | — |
| RoMa，有标注，没见过 | 0.319 | 0.272 |
| RoMa，有标注，见过 | 0.347 | 0.331 |

**实验结论**

在没见过的区域上，用真实标注训练的 LoFTR 不如现有的无标注方法：Val 0.267、Test 0.238，无标注方法为 0.29 左右和 0.26 左右。有标注训练比 zero-shot 高约 0.05，但见过与没见过之间差 0.04–0.06，说明在几百对标注上训练得到的提升有相当一部分不能迁移到别的区域。RoMa 也有同样的落差（Val 0.319 对 0.347，Test 0.272 对 0.331）。

推测原因是训练数据的规模和多样性：有标注的训练只有 652 或 953 对、来自很少几个区域，而无标注方法用的是训练集的 7907 对。由此看，在本数据集上，无标注方法利用大量未标注数据得到的收益，已经超过在少量标注上做有监督训练的收益。这一点未经验证：两边的训练数据量、区域数和训练配方都不同，每个设置也只跑了一个种子。

这里的有监督结果不能当作「有标注时的上限」：如果训练集也有标注，有监督训练能到多少，本实验无法回答。
