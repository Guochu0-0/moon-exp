# 平均参照配方三个种子的权重不超过最好的单个种子

**摘要**

参照配方（RoMa 自训练，解冻 VGG、学习率 3e-5）三个种子在 Val AUC@5 峰值处的存档分别为 0.316、0.316、0.319。Model soups（2203.05482）报告同一起点微调出的模型直接平均权重，往往比最好的单模型更好，而且不增加推理开销。我们把三个存档逐参数平均，也按 Val 从高到低贪心地只平均前两个。三个平均得 0.318，前两个平均得 0.317，都不超过最好的单个种子 0.319。权重平均不保留。

**引言**

RoMa 自训练停在约 0.31（M），同一配方不同种子之间差别很小。种子之间若落在同一个损失盆地，平均权重相当于取盆地中心，在分布偏移下通常更稳（Model soups §3、WiSE-FT 2109.01903）。本数据的 Val、Test 都是训练时没见过的区域，正是这类偏移。权重平均不用训练，代价只是一次评测，所以放在第一批。

**方法**

*模型。* 参照配方三个种子的 Val 峰值存档：M15s2 第 4000 步（Val 0.3188）、M15s1 第 8000 步（0.3160）、M15 第 7000 步（0.3156），都从同一个 AnyMatch RoMa 权重出发。

*平均。* 所有浮点张量（参数与 BN 统计）逐元素均匀平均，整数张量取第一个。*三个平均*（`main`）平均全部三个；*前两个平均*（`main__top2`）按 Model soups 的贪心汤，从 Val 最高的开始加入第二个。贪心汤的规则是加入后 Val 不降才保留。

*评测。* 评测链路与训练出的方法相同（560 → 864，symmetric）。没有训练曲线，所以与各种子的 Val 峰值比，而不是与后段均值比。

**结果**

*平均没有超过最好的单个种子。*

| 方法 | Val AUC@5 | Test AUC@5 |
|---|---|---|
| 最好的单个种子（M15s2 第 4000 步） | 0.319 | — |
| 前两个平均 | 0.317 | 0.287 |
| 三个平均 | 0.318 | 0.289 |
| 三个种子峰值的均值 | 0.317 | — |

表 1：三个平均比三个种子峰值的均值高 0.001，比最好的单个低 0.001。

*贪心汤停在单个模型。* 加入第二个种子后 Val 从 0.319 降到 0.317，按贪心规则不加入，贪心汤就是最好的单个种子。

**讨论**

平均后没有出现误差壁垒（Model soups §3.3.1 中学习率高时会出现），三个平均仍是一个正常的模型，说明三个种子落在同一盆地；但盆地中心并不比各点更好，种子之间的差别本来就只有 ±0.002。平均能稳住，但不能提高。参照的 Test 未在 M 中评测，表中只有平均后的 Test，留作记录。
