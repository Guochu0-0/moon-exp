# 强化学习里的 EMA：拿它出伪标签，还是拿它当约束锚点

> 调研日期：2026-10-27。对应地图 #161；接着 #214 的调研写。
> 我们的设置：用无标注强化学习微调 RoMa，做月球光学图与 SAR 图的配准。打分用的参照仿射来自模型自己的正常推理加 RANSAC；粗匹配在每格的概率分布上抽 16 次，用 RLOO 留一基线做策略梯度，每批数据只更新一次参数，没有 KL 项，也没有 clip。参照跟着模型漂，会出现自洽坍缩（CONTEXT.md，runs/E26、E27）。E30 试过 EMA 参照（τ = 0.99 / 0.996 / 0.999）；E32 同时训细化，种子 0 的 6 组里只有 EMA 参照、EMA 参照 + 检查两组训满 2000 次更新（Val AUC@5 0.312 / 0.311），其余组都在 700 次更新以内越线。只有一个种子。
> 标注约定：**【原文】** 指论文正文或附录里写的；**【代码】** 指读了作者公开的代码；**【推断】** 是我的判断。出处见 [sources.md](sources.md)。
> 不重复的内容：Mean Teacher、BYOL、DINO 的 EMA 目标网络和 τ 消融，SRT 的自奖励坍缩，以及「每批只更新一次时 PPO clip 是空操作」的分析，都在 #214 的调研里（分支 `research/self-ref-collapse`，`docs/research/self-ref-collapse/README.md` 第 2 节），这里只引用结论。

先解释两个词：
- **EMA（指数滑动平均）**：另存一份参数 θ_EMA，每次更新后按 θ_EMA ← τ·θ_EMA + (1−τ)·θ 向当前参数挪一小步。τ 叫衰减率，越接近 1 跟得越慢；1/(1−τ) 大致是它落后当前模型的步数（时间常数）。有的论文把 1−τ 写成更新率 μ 或 α，下文会注明。
- **锚点**：强化学习里常加一项 KL 散度（衡量两个概率分布差多少），把当前策略往某个「锚点策略」拉。经典做法的锚点是冻结的初始模型；PPO 的 clip 也起同样作用，锚点是采样时的旧策略。

## 0. 结论速览

1. 五篇工作里，EMA 有两种完全不同的用法。**出伪标签**：Co-rewarding-II/III、M-GRPO 用 EMA 模型产生打分用的目标，和我们的 EMA 参照是同一种做法。**当锚点**：EMA-PG、WARP、PPO-EWMA 用 EMA 模型做 KL 或 clip 的锚点，奖励本身不来自模型。前一类直接对应我们的问题；后一类管的是「策略每步能走多远」，我们目前没有这一项。【原文 + 推断】
2. 对我们最直接的证据来自 Co-rewarding。它的消融「w/o Updating Reference」（教师不更新，等于冻结）在 4 组设置上普遍比 EMA 教师差，伪标签准确率停在约 25%，EMA 教师则持续上升（表 3，附录 D.2）。这和 #214 引用的 BYOL τ=1 结果同向：冻结参照稳定但不长进。【原文】
3. **τ 的日程**：Co-rewarding 让 EMA 系数按余弦从 0.99 升到 0.9999，即「前快后慢」。论文没有对这个日程做消融，公开脚本里的终点实际是 0.99999。M-GRPO、WARP、EMA-PG 都用常数。所以「前快后慢」目前只有做法，没有证据说明它比常数好。【原文 + 代码】
4. **单靠第二视角不够，要和 EMA 教师合用**：Co-rewarding-I（只用改写题的交叉投票，不用 EMA）在 MATH 上稳定，在 DAPO-14k 上仍然坍缩（§4.2.2）；II 和 III 都没有坍缩。这和 E32 里变换一致性检验单独用时越线、EMA 参照组训满的现象同向，但两边任务差别很大，只能算旁证。【原文 + 推断】
5. **EMA 当锚点时，clip 不再是空操作**：#214 说过，我们每批只更新一次，所以 PPO clip 的比率恒为 1，clip 不起作用。PPO-EWMA 把 clip 和 KL 的锚点从「采样时的策略」换成 EWMA 策略。这时比率是 π_θ/π_EWMA，单次更新下也不恒为 1，clip 会生效。它的 PPG 实验本来就是每批一遍（E_π = 1）。【原文 + 推断】

## 1. Co-rewarding（Zhang et al., ICLR 2026，arXiv 2508.00410）

**场景**：大语言模型做数学推理，用 GRPO 训练，不用标准答案。基线是「自奖励」：对同一道题采 G 个回答，多数投票的答案当伪标签，和伪标签一致记 1 分。另有两种基线分别用熵和 self-certainty（模型对自己输出的置信度）当奖励。【原文 §1、§4】

**坍缩表现**：作者称之为「自洽的错觉」导致的奖励钻空子（reward hacking）。多数投票类奖励会收敛到「一致但错误、在各回答间共识很高」的答案；熵类奖励会重复同一个词元直到被截断（§1，图 1 右，图 4）。三种自奖励基线在 MATH 和 DAPO-14k 上都是先涨后坍（§4.2.2，图 3、图 5）。多数投票的伪标签准确率先短暂上升，然后掉到接近 0（图 6）。【原文】这和我们「模型与参照一起落到与图像无关的平凡解」是同一类现象：打分目标来自模型自己，只要两者一致，奖励就高。【推断】

**三个版本**【原文 §3.2，附录 A、B.1】
- **Co-rewarding-I（数据侧）**：用 Qwen3-32B 把每道题改写成语义相同的另一道题。原题的回答用改写题回答的多数投票打分，改写题的回答用原题回答的多数投票打分（式 7、8）。
- **Co-rewarding-II（模型侧）**：另有一个「参照教师」π̃_ref，它对同一道题采 G̃ = 8 个回答，多数投票作伪标签，给策略的 G = 8 个回答打分（式 9、10）。教师参数按 EMA 跟随策略（式 11）：
  π̃_ref^(k) ← α^(k)·π̃_ref^(k−1) + (1−α^(k))·π_θold^(k)
  其中 α^(k) 按余弦退火从 α_start = 0.99 升到 α_end = 0.9999（§4.1，附录表 5）。原文的说法是「教师开始时更新快，之后越来越慢」。
- **Co-rewarding-III（两者合用）**：教师同时对原题和改写题采样，改写题上教师的投票给原题的回答打分，反过来也一样（式 12–14，算法 3）。EMA 更新同式 11。

**公式与代码的出入**【原文 + 代码】
- 论文式 11 印出来的形式是 α^(k) = 1 − (α_end − α_start)/2·(1 + cos(πk/K))，代入起止值后与文字描述不一致：k = 0 时约 0.9901，k = K 时为 1，而不是 0.9999。
- 官方代码（`Co-rewarding-II/verl/workers/sharding_manager/fsdp_vllm.py`）里的变量是「策略所占权重」a = 1 − α：a(t) = a_end + ½(a_start − a_end)(1 + cos(πt/T))，教师 ← a·策略 + (1−a)·教师。运行脚本 `run_corewarding-II.sh` 设 a_start = 0.01、a_end = 1e-5，即教师衰减率从 0.99 升到 **0.99999**，比论文写的 0.9999 还慢一个数量级。每个训练步都更新（`update_interval=1`）。
- 同一份代码里，EMA 教师就是 verl 的 ref 模块。这个模块同时被用来算 KL 损失的参照对数概率（`kl_loss_coef=0.001`，`low_var_kl`）。所以 Co-rewarding-II 实际上**既用 EMA 出伪标签，又以同一份 EMA 作 KL 锚点**，只是 KL 系数很小。论文正文没有点出这一点。

**训练规模**：学习率 3e-6，批大小 128，MATH 上训 170–220 步，DAPO-14k 上 300–330 步，clip 0.2（附录表 5）。【原文】按代码的日程，教师开始时落后约 100 步，与整个训练长度相当。【推断】

**关键数字**【原文】
- 主结果（表 1、表 2，列依次为 MATH500 / GSM8K / AMC / AIME24）：
  - Qwen3-8B-Base，在 MATH 上训：有标注 GRPO 82.6 / 87.26 / 54.22 / 17.15；多数投票 79.8 / 89.76 / 49.09 / 15.83；I 81.2 / 93.70 / 51.20 / 15.10；II 80.8 / 92.42 / 53.46 / 14.48；III 81.4 / 90.98 / 54.07 / 13.33。
  - Qwen3-8B-Base，在 DAPO-14k 上训：有标注 86.6 / 87.19 / 61.75 / 24.58；多数投票 78.6 / 91.66 / 50.00 / 11.25；I 78.4 / 88.02 / 51.20 / 11.88；II 80.6 / 94.01 / 54.37 / 16.35；III 81.6 / 92.27 / 53.77 / 17.71。
  - Llama-3.2-3B-Instruct 在 MATH 上训，III 的 MATH500 为 51.6，多数投票为 46.8，有标注 GRPO 为 47.0。
  - II 与 III 互有高低，III 并不全面占优。
- **去掉 EMA 更新的消融**（表 3，「w/o Updating Reference」）。教师固定不动，其余同 II。四组设置中，MATH500 下降 1.6–4.8，GSM8K 下降 0.4–5.6；少数指标持平或略升，例如 Qwen3-8B / MATH 的 LiveCode 30.62 对 30.23。
- **伪标签准确率**（图 6，附录 D.2）：EMA 教师「随训练稳步上升」；不更新的教师「保持在约 25%」；多数投票基线先升后跌到接近 0。
- **稳定性**：Co-rewarding-I 在 MATH 上稳定，在 DAPO-14k 上「仍然坍缩」，作者认为 I 的稳定性取决于训练数据（§4.2.2）。

**没有的消融**【原文】：没有对 α 的起止值或余弦日程本身做消融，也没有和常数 α、按固定间隔硬更新比较（正文和附录都没找到）。

**局限**：没有独立的局限性小节。I 依赖改写质量（§3.2）。多数投票只适用于答案可以比对是否相同的任务。我没有读到正文里关于种子数和方差的说明。【原文 + 推断】

## 2. M-GRPO（Bai, Wu, Ye, Chen；NeurIPS 2025 Efficient Reasoning 研讨会；arXiv 2512.13070）

**出处说明**：NeurIPS 页面（neurips.cc/virtual/2025/126709）显示这是**研讨会海报**（The First Workshop on Efficient Reasoning），不是主会论文。正文读的是 arXiv v1。【原文】

**场景**：在 MATH 训练集上做自监督 RLVR（可验证奖励的强化学习，这里不用答案），伪标签由多数投票产生。主干是 Qwen3-4B-Base；复现了 SRT 和 Intuitor 作基线（§3，图 5）。【原文】

**坍缩表现**：「策略坍缩」，即训练奖励先升后降，验证准确率随之下跌（§1，图 1，图 5）。SRT 最终存档在 MATH500 上只有 47.50，人工挑出的最好存档为 79.20（表 2）。增加每题的回答数 G 只能**推迟**坍缩：峰值从 76.15（G = 16）升到 79.20（G = 64），但每个 G 最后都坍缩（表 1，图 1）。另有策略熵早期急剧下降（图 2 左）。【原文】

**EMA 用在哪里**：出伪标签。动量模型 θ_k ← m·θ_k + (1−m)·θ_q（式 1）。对每道题，当前策略采 M 个回答，动量模型采 N 个，合成 G = M + N 个回答一起多数投票得到伪标签；实验取 N = G/4。优势（advantage）只在当前策略的 M 个回答之间做归一化，只有这些回答进入梯度（§2.1，式 2、3）。此外，熵低于 Q1 − 0.75·(Q3 − Q1) 的回答会在投票前被剔除，Q1、Q3 是四分位数，作者称这一步为 IQR 过滤（§2.2，算法 1）。【原文】

**超参数**：正文只写 m「例如 0.99」，没写实验用值，也没有日程。【原文】公开代码在每次策略更新后调用 `update_momentum_rollout(m=0.99)`，注释写明这是硬编码的常数（`verl-intuitor/verl/workers/fsdp_workers.py`）。KL 系数 0.005（表 4），论文没有说 KL 锚点是谁。【代码 + 原文】

**关键数字**：M-GRPO + IQR 的最终存档 MATH500 为 79.75，AIME24 为 14.58（表 2）；G 从 8 加到 256，MATH500 依次为 77.60 / 79.75 / 79.75 / 79.50（表 3）。【原文】

**局限**【原文 + 推断】
- 没有任何消融：不比较「去掉动量模型」，不扫 m，不扫 N，也不单独评估 IQR 过滤。所以「动量模型防坍缩」只有和 SRT 的整体对比作证据，而两者还差了 IQR 过滤。
- 每个设置只有一次运行。
- 表 2 有两行都标作「SRT_Final」，数值不同；§4.1 引用的 GPQA 数字与表 2 对不上。
- 只是研讨会论文，证据强度明显低于 Co-rewarding。

## 3. EMA Policy Gradient（Zhang & Ba，arXiv 2602.04417；ICML 2026）

**出处说明**：arXiv 只有 v1（2026-02-04），页面没有会议标注。ICML 2026 官网的日程页（icml.cc/virtual/2026/70431 等）列有此文，未见其他接收信息。【原文】

**场景**：大语言模型的数学推理（DeepSeek-R1 蒸馏的 Qwen-1.5B）和带搜索工具的问答（Qwen-3B）。奖励来自标准答案，**不是**无标注设置。【原文】

**问题**：作者的出发点是 DQN 的目标网络能「提供稳定的监督目标」，而不是某种具体的坍缩。论文说，全参数微调（不用 LoRA）时「保留一个小的 β > 0 对防止训练坍缩是必要的」，但没有给数字（§6）。【原文】

**EMA 用在哪里**：KL 锚点。把 GRPO 里 KL 项的固定参照模型换成 EMA：θ_ema ← η·θ_ema + (1−η)·θ，初值为 θ_0（式 2）。KL 是逐词元的正则项，放在损失里，不加到奖励上：θ ← θ + α(A·∇log π − β·∇KL̂(π_θ ‖ π_θema))。另提出 Top-k KL 估计器：前 k 个词元精确计算，其余部分用采样估计。【原文 §1、§5.1】

**超参数**【原文 + 代码】
- 附录 A：学习率 1e-6，全参数微调，β = 0.001，EMA 每 T_ema = 10 步更新一次。作者说这一做法沿用 DQN「目标网络定期更新」的经验。
- 正文图 7 建议 η 取 [0.9, 0.95]（配 k = 32），并称结果对 η 和 KL 方向都不敏感，具体数值只在图里。
- 官方脚本 `train_deepscaler_8k_ema_pg.sh`：`ref_policy_ema_tau=0.95`，`ref_policy_ema_update_period=10`。按「每 10 步更新一次、每次 η = 0.95」算，锚点大约落后 10/(1−0.95) = 200 步。【推断】
- η 是常数，没有日程。

**稳定性条件**（§4，附录 C.4）【原文】：把 KL 在 EMA 锚点附近做二次近似，Fisher 矩阵最大特征值记为 λ_max，学习率记为 α。假设梯度和 Fisher 在若干步内变化不大，当前参数与锚点之差 δ 在每个特征方向上按系数 χ_i = η − αβλ_i 递推（引理 4.2）。稳定的充要条件是 **αβλ_max < 1 + η**（式 9）：
- αβλ_max ≤ η：稳定，不振荡；
- η < αβλ_max < 1 + η：稳定，但会振荡；
- αβλ_max ≥ 1 + η：发散。
另外，在二次近似下增大 η 会让准稳态 KL 变大，除非同时加大 β 或减小 α（附录 C.5.2）。

**关键数字**【原文】
- 数学（表 3，Pass@1 平均）：GRPO 0.503，EMA-PG 0.528；OlympiadBench 50.8% → 53.9%。
- 搜索问答（表 2，7 个数据集平均）：GRPO 0.312；只换 EMA 锚点 0.348；再加 Top-k 正向 KL 0.406，或加 Top-k 反向 KL 0.416。
- 论文里有一组「序列级 KL + EMA 锚点」（作者称之为 WARP 式）只有 0.106，远低于 GRPO。但这组同时改了 KL 的形式，不是对 EMA 的干净消融。
- 没有「固定锚点、只改 KL 估计器」的单独数字表；EMA 锚点的作用主要靠表 2 的「EMA anchor only」一行看出。
- 摘要里的两个数据集名与表 2 的列对不上：29.7→44.1 在表里是 TriviaQA，摘要写成 HotpotQA。

**局限**：没有独立局限性小节。稳定性结论建立在「变化缓慢」与「二次近似」两个假设上，而且分析用的是纯 SGD 步，不是 Adam。只在两类任务、1.5B 和 3B 模型上做过。【原文 + 推断】

## 4. WARP（Ramé et al., Google DeepMind, 2024，arXiv 2406.16768）

**场景**：RLHF（用人类偏好训练的奖励模型来做强化学习），Gemma 7B。奖励来自奖励模型。arXiv 页面没有会议标注。【原文】

**问题**：KL 锚点是固定的 SFT 模型时，「减小 KL」和「提高奖励」之间有根本矛盾，奖励会学不上去；不加 KL（β = 0）时，奖励很快上涨、KL 在几步内爆炸，即奖励钻空子（§1，§4.1 图 3a–b）。【原文】

**EMA 用在哪里**：KL 锚点。三步中的第一步是 θ_ema ← (1−μ)·θ_ema + μ·θ_policy，每个训练步更新，μ = 0.01、β = 0.1（§3.1，§4 设置），μ 为常数。§4.1 有一处写成 μ = 0.1，与其余处冲突，看起来是笔误。原文对它的解释是：EMA 锚点让 KL 约束「逐步自动退火、放松」，同时策略相当于在从一个「动态的 mean teacher」做 KL 蒸馏（观察 1）。第二步用 SLERP（球面插值）合并独立训练的 2 个策略，第三步把合并结果往初始模型插回去一部分（LITI，η = 0.3），再作为下一轮的初值，共迭代 5 轮。【原文 §3】

**关键结果**【原文】
- 图 3a–b：SFT 锚点下，β = 0.1 时奖励饱和在约 −0.62，β = 0.01 时饱和在约 −0.46；EMA 锚点的 KL-奖励帕累托前沿「在左上方」，即同样 KL 下奖励更高。
- 附录 D.2：μ 只试了 0.01（β = 0.1）和 0.005（β = 0.2）。原文结论：「减小 μ 和增大 β 效果相似，都能略微改善 KL-奖励前沿，但训练变慢」。
- 迭代到第 3 轮后提升停滞（表 1，§4.4）。

**局限**：奖励模型只在 KL 小的区域可信；每轮要跑多个强化学习运行，开销大；只用了一个基座模型（§4、§6）。【原文】WARP 关心的是如何在奖励和遗忘之间权衡，不是自奖励坍缩。【推断】

## 5. PPO-EWMA（Hilton, Cobbe, Schulman，NeurIPS 2022，arXiv 2110.00641；代码 github.com/openai/ppo-ewma）

论文题目是「Batch size-invariance for policy optimization」。

**场景**：Procgen 16 个游戏环境，奖励来自环境。研究的问题是「换批大小后，能否只调其他超参数就得到同样的结果」，以及数据过时（staleness）时 PPO 为什么会退化。【原文 §1、§5】

**核心观察**：PPO 目标里的旧策略 π_old 其实有两个用途。一是重要性采样比率，必须用采样时的策略，称「行为策略」π_behav；二是 clip 或 KL 把当前策略往回拉的目标，作者称「近端策略」π_prox。两者可以分开：重要的是近端策略有多旧，而它是不是被用来采样并不重要（§2）。分开后的 clip 目标是 E[(π_prox/π_behav)·min(r·A, clip(r, 1−ε, 1+ε)·A)]，其中 r = π_θ/π_prox。【原文】

**EMA 用在哪里**：近端约束的锚点。每次梯度更新后维护策略网络参数的 EWMA，用它作 π_prox（§4）。注意它是带归一化的加权平均（权重 1, β, β², …，再除以权重和，附录 A），刚开始时不会偏向初值。衰减率 β_prox = 0.889，使 EWMA 的「重心年龄」1/(1−β_prox) − 1 = 8 个梯度步，等于原 PPG 每轮的小批次数；调参时还试了重心为 2 和 32 的取值，都没有更好（附录 B，表 4）。批大小缩小为 1/c 时，把重心乘 c，保持近端策略「以环境步计的年龄」不变（§4）。β_prox 是常数。【原文】

**关键结果**【原文】
- 人为数据过时（图 1，16 个环境平均，4 个种子）：π_old 取最近策略时，「哪怕少量过时也会让训练高度不稳定」；分开行为策略和近端策略后，直到过时约 8 轮迭代（超过 50 万环境步）才明显退化。
- 批大小不变性（§5.2，图 2、3）：最大与最小批大小的最终归一化回报相差 0.052，去掉 Heist 这个离群环境后为 0.019。消融中「去掉对 EWMA 的调整」在每个批大小上都只有小影响。
- EWMA 的直接收益（§5.3，图 4）：「小但非常一致」，在后 8 个环境上，PPO 和 PPG 都全部胜过不带 EWMA 的版本。作者归因于 EWMA 降低了近端策略的方差。代价是 PPO 计算量增加 30%（墙钟时间增加 19%）。
- 附录 G：把近端策略的重心年龄减半，效果和把 KL 系数加倍类似（作者比作「橡皮筋拴的点近一半」和「橡皮筋粗一倍」）。但这只在局部成立：一直减半重心、一直加倍系数，性能会逐渐变差，因为年龄太小时 θ − θ_prox 的噪声变大（StarPilot 上的网格搜索，图 18）。

**局限**：任务是有真实奖励的游戏，不涉及坍缩；β_prox 只在 PPG 的前 8 个环境上调过，没有为 PPO-EWMA 单独调。【原文】

## 8. 对本项目的启示

只给方向和依据，不设计实验，由用户决定是否做。

**8.1 EMA 参照本身：方向有文献支撑，但我们的证据还薄**
- Co-rewarding-II 与我们的 EMA 参照结构相同：都由 EMA 模型推理出打分目标，当前模型的样本向它看齐。它的「冻结教师」消融差于 EMA 教师（表 3、图 6），加上 #214 引用的 BYOL、DINO，三者结论一致：参照的惯性要介于「即时」和「冻结」之间。【原文】
- E32 只有种子 0，E30 的 24 个运行连底座都健康，分不出差别。文献的结论能说明方向对，但不能替我们回答「失效率降了多少」。【推断】
- BYOL 和 Mean Teacher 都说 EMA 本身不防平凡解（#214 第 2 节）。Co-rewarding 和 M-GRPO 也都没有声称 EMA 能排除平凡解，只说「训练更稳」。M-GRPO 还同时用了 IQR 过滤，没有拆开评估。【原文】所以 EMA 参照 + 合理性检查或其他防平凡解的手段，仍是 #214 建议的组合。【推断】

**8.2 τ 的日程（前快后慢）：有人这么用，没有证据说它更好**
- Co-rewarding 用余弦从 0.99 升到 0.9999（代码为 0.99999），BYOL、DINO 也是升到 1（#214）。三者都没有把「日程」和「常数」直接比较过。【原文】
- 要注意跟训练长度的比例。Co-rewarding 只训 170–330 步，起点的时间常数约 100 步，已经是训练长度的三分之一到一半。我们训 2000 次更新，τ = 0.999 的时间常数 1000 次，比例相近；τ = 0.99 只有 100 次，比例小得多。【原文数字 + 推断】
- E32 的越线都发生在第 200–700 次更新，也就是训练前期。「前快后慢」意味着前期参照跟得更紧，恰好落在我们最容易出事的阶段。所以照搬余弦日程的方向未必对我们有利；如果要用日程，从多慢起步是关键。【推断】
- EMA-PG 附录 C.5.2 指出，η 越大，准稳态 KL 越大。这是 KL 锚点下的结论，在我们这里的类比是「τ 越大，当前模型与参照的距离越大」。E30 的日志与此一致：「与慢速参照的距离」在 τ = 0.99 时为 9–12 px，在 0.999 时为 16–30 px。距离太大，参照对当前样本的打分就会变旧。【原文 + 推断】

**8.3 EMA 参照 + 第二视角（Co-rewarding-III 式）**
- Co-rewarding-III 的做法是：EMA 教师在另一个视角（改写题）上的结论，用来给原视角的样本打分。搬到我们这里就是：对 SAR 施加另一个已知仿射 T₂，由 EMA 模型推理、换算回原坐标，给在 T₁ 下抽到的样本打分。这相当于把 E31 的变换一致性检验和 EMA 参照合在一起，并且把检验从「过滤」改成「交叉出参照」。【推断】
- 文献证据：Co-rewarding-I（只有第二视角、没有 EMA）在 DAPO-14k 上仍然坍缩，而 II 和 III 都不坍缩；III 相对 II 的分数互有高低（表 1、2）。所以第二视角的增益主要在 EMA 之上锦上添花，不能替代 EMA。【原文】E32 里变换一致性检验单独用时在第 677 次更新越线，与此同向。【推断】
- #214 指出，双扰动等变可以从原理上排除「钉在 SAR 画面某处、与内容无关的单点解」。EMA 防不了平凡解，它补的正是这一块。两者合用在机制上互补。【推断，依据 #214 第 1 节】

**8.4 M-GRPO 式的混合：当前模型与 EMA 模型一起出参照**
- M-GRPO 让动量模型贡献投票池的 1/4，伪标签由两者合并投票产生（§2.1）。搬到我们这里，可以把当前模型和 EMA 模型的对应点合起来做 RANSAC，或者两者的仿射取逐格中位数。这是介于「当前参照」和「纯 EMA 参照」之间的做法。【推断】
- 证据很弱：M-GRPO 没有任何消融，又只是研讨会论文。【原文】

**8.5 对 EMA 模型加 KL 或近端约束（第二种用法）**
- 这和「EMA 出参照」管的是两件事：参照决定往哪走，KL 或 clip 决定每步最多走多远。我们目前两项都没有。【推断】
- #214 说「clip 是空操作」，前提是 clip 的锚点是采样时的策略。PPO-EWMA 的分开写法里，锚点是 EWMA 策略，比率 π_θ/π_EWMA 不恒为 1，单次更新下 clip 也会起作用。PPG-EWMA 的策略阶段本来就是每批只过一遍（附录 B 表 3，E_π = 1）。【原文 + 推断】
- 对 EMA 的 KL 和 #214 不推荐的「对初始模型的 KL」性质不同。后者相当于软冻结参照，SRT 报告它无效；前者的锚点会跟着走，WARP 和 EMA-PG 都报告它优于固定锚点（WARP 图 3；EMA-PG 表 2，0.312 → 0.348）。但这两篇都有真实奖励，不涉及自洽坍缩。【原文 + 推断】
- Co-rewarding-II 的代码实际已经是「EMA 出伪标签 + 对同一份 EMA 加 KL（系数 0.001）」。论文没有把 KL 拆开做消融，所以这一项的作用不明。【代码】
- 如果加 KL，EMA-PG 的稳定条件 αβλ_max < 1 + η 是现成的参考。但它是对纯 SGD 推的，我们用的是 AdamW，逐参数归一化会改变有效步长。只能当量级参考，不能直接套用。【原文 + 推断】
- 我们的动作是每格在 64×64 个锚点上的 softmax，每格可以直接算精确 KL，不需要 EMA-PG 的 Top-k 估计器。【推断】

**8.6 时间常数与 KL 强度可以互换（PPO-EWMA 附录 G）**
- 锚点年龄减半，大致等于 KL 系数加倍，但只在局部成立；年龄太小，噪声会变大。WARP 附录 D.2 的说法与此一致：减小 μ 与增大 β 效果相似。【原文】
- 如果以后同时用 EMA 参照和对 EMA 的约束，τ 和约束强度就不是两个独立的旋钮，扫参时要一起看。【推断】
