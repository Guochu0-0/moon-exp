# 照原概率在粗匹配上抽签做强化学习：三种评分都没有超过未训练的 RoMa，随机评分也把概率压到了一个位置上

**摘要**

我们想在不用标注的情况下，用强化学习改进 RoMa 在月球光学图和 SAR 图之间的配准。RoMa 匹配的第一步是粗匹配：对一张图上的每个小格子，给另一张图上 4096 个候选位置各打一个分，正常使用时取最高分的那个。强化学习把“取最高分”改成“按概率抽签”：同一对图抽 16 次，用一个不需要标注的评分给每次的结果打分，再让模型提高比平均好的那几次抽签的概率。此前的检查表明，未训练模型的概率很分散，抽签不缺变化；但真正训练起来能不能学到东西，还没有试过。我们从未训练的模型出发，用三种评分各训练两次（随机种子不同），每次 4000 步。灰度相关评分看按这次匹配对齐两图后，两图的灰度像不像；吻合度评分看每个格子的匹配和这次匹配整体拟合出的仿射是否一致；随机评分只是随机数，作为对照。结果没有一个模型超过未训练时的配准精度（验证集 AUC@5 为 0.236），离离线伪标签自训练的 0.328 更远。灰度相关评分在 1000 步时让 AUC@5 跌到 0.015 和 0.086，之后回升，4000 步时为 0.234，与未训练时持平。吻合度评分在训练中越来越高，配准却失效，配准误差的中位数升到约 100 像素。随机评分和抽到什么无关，却在 1000–2000 步内把每个格子的概率几乎全压到一个位置上，配准同样失效。这些结果说明了训练失败的样子，但不足以判断失败的原因。

**引言**

月球光学图和 SAR 图之间没有可用的配准标注，所以我们只比较不需要标注的训练方法。目前最好的是离线伪标签自训练（noisy student）：先用模型给训练图做匹配，把它有把握的输出当作标签，再用这些标签训练模型，反复几轮。在较大的几何扰动下训练（平移半径 128 像素、旋转 ±20°、缩放 ±20%），RoMa 用这种方法在验证集上的 AUC@5 达到 0.328，未训练时为 0.236。伪标签只能教模型重复它已经做对的部分。强化学习则按一个评分直接调整模型的输出，不受这个限制，前提是评分本身不需要标注。

RoMa 分两步找两张图之间的对应。第一步是粗匹配：把输入图（560×560）切成 40×40 个格子，每个格子去另一张图上找大致的落点。另一张图上预先均匀铺了一张 64×64 的固定网格，共 4096 个候选位置。模型对每个格子给这 4096 个位置各打一个分，分数转成概率后加起来等于 1。正常使用时，每格取概率最高的位置（下称最高分位置），再和它上下左右 4 个邻居按概率加权平均，得到一个具体坐标。第二步是细化：从粗匹配出发，在 5 个越来越细的尺度上一级级修正，最后得到逐像素的匹配。

强化学习需要随机性，最直接的来源就是粗匹配：按每格的概率抽一个位置，代替最高分位置，其余照常计算。此前在 200 对训练图上做过一次检查，发现未训练模型的概率很分散：照原概率抽签，96% 的格子抽到的不是最高分位置；训练信号也确实能沿粗匹配传到我们想训练的那部分网络。也就是说，抽签不缺变化，信号也有去处。还没检验的有两件事：用不需要标注的评分训练，能不能超过未训练的模型；以及模型的变化是不是真的由评分带来。后一件需要一个对照：如果用和结果无关的随机数当评分，模型应当基本不动。

本文照原概率抽签，用两种不需要标注的评分和一个随机评分，从未训练的模型开始训练，比较它们在验证集上的配准精度，并记录训练中每格概率的形状怎样变化。

**方法**

*模型与数据。* 模型用 AnyMatch 发布的 RoMa 权重。RoMa 用 DINOv2 网络提取粗匹配所需的特征；我们在 DINOv2 每一层的注意力投影上挂了一小块可训练的附加参数（秩为 8 的 LoRA），它的初值让模型输出和原来完全相同，所以训练开始时模型就是未训练的模型。训练集是 7907 对训练图，扰动和离线伪标签自训练用的一样：对 SAR 图做随机平移（在半径 128 像素的圆内）、旋转（±20°）和缩放（±20%），再随机擦掉 1–3 块，不改亮度。

*抽签。* 每步取 1 对图，抽 16 次，温度为 1，即直接用模型原本的概率。每次在每个格子上独立抽一个位置，代替最高分位置；粗匹配的其余部分和细化都照正常流程计算，得到一份逐像素匹配。细化部分不参与训练。

*三种评分。* 评分就是强化学习里的 reward，三种都只用图像和这次抽签的结果本身。每次抽签的结果先按正常流程拟合一个仿射：按可信度（模型对每个像素给出的 0 到 1 之间的把握）挑 5000 个匹配点，用 RANSAC 拟合，阈值 3 像素。

- 灰度相关评分：用拟合出的仿射把 SAR 图对齐到光学图上，在两图重叠、且不在 SAR 图对齐后边缘补零的区域里，算两图灰度的归一化互相关（NCC；1 表示完全相像，0 表示无关）。仿射拟合失败时记 −1。每次抽签得到一个分。
- 吻合度评分：每个像素的匹配和这次仿射差 r 像素，代入 max(0, 1 − (r/3)²)：差 0 得 1 分，差 3 像素及以上得 0 分，再在每个格子内平均。每个格子得到一个分。
- 随机评分：每个格子取一个 0 到 1 之间的均匀随机数，和抽到什么无关，作为对照。

*更新。* 更新按 RLOO 的做法（《Back to Basics: Revisiting REINFORCE Style Optimization for Learning from Human Feedback in LLMs》，arXiv 2402.14740）。每次抽签（吻合度评分和随机评分则是每个格子）的“优势”是它的评分减去同组其余 15 次的平均。损失是负的优势乘以抽到位置的对数概率，再取平均；效果是比同组平均好的抽签概率被调高，差的被调低。优势不除以标准差，也不加把模型拉回起点的惩罚项。训练信号沿粗匹配传到 DINOv2 上的 LoRA 和粗匹配用到的几个模块（打分的解码器、比较两图特征的模块、特征投影层），传不到细化部分和 VGG。优化器为 AdamW，学习率 3e-5（LoRA 为 1e-4），权重衰减 0.01；前 500 步从 0.1 倍升到全值，之后按余弦曲线降到 0，共 4000 步。每种评分用种子 0 和 1 各训练一次。

*评测。* 每 1000 步存一次权重，在不加扰动的验证集（652 对）上评测。配准误差是估计的仿射和标注的仿射把图块 4 个角映射到的位置之间的平均距离。AUC@5 是“误差不超过 x 像素的图对比例”这条曲线在 x 从 0 到 5 像素之间的面积，再除以 5，越接近 1 越好。每次训练选验证集 AUC@5 最高的存档（不含第 0 步），再在测试集（953 对）上评测。参考值取同样扰动下的结果：未训练的 RoMa 在验证集和测试集上为 0.236 和 0.231，离线伪标签自训练为 0.328 和 0.301。

*概率的形状。* 训练中每步记两个量，在 100 步的窗口内平均。一是每格的熵，它衡量概率摊得有多开：e 的熵次方约等于“相当于平摊在几个位置上”，熵为 0 表示全在 1 个位置上，熵为 8.32 表示平摊在全部 4096 个位置上。二是最高分位置的概率，越接近 1，抽签越是每次都抽到同一个位置。

**结果**

*灰度相关评分在 1000 步时让配准变差，4000 步时回到未训练时的水平。* 训练 1000 步时，两个种子的验证集 AUC@5 分别跌到 0.015 和 0.086（表 1）。之后 AUC@5 逐步回升（同一时段学习率按余弦曲线变小），4000 步时两个种子都是 0.234，与未训练时的 0.236 持平。测试集上为 0.222 和 0.218，略低于未训练时的 0.231。种子 0 的概率在 1000 步附近一度几乎集中到一个位置上：熵为 0.56（相当于约 2 个位置），最高分位置的概率为 0.90；这时平均每次抽签的评分也降到 −0.064。之后概率重新摊开，最后熵为 3.6（相当于约 36 个位置；表 2）。

*吻合度评分越训越高，配准却失效。* 种子 0 的平均评分在 1000 步附近从 0.10 升到 0.30，同时每个存档的验证集 AUC@5 都是 0，配准误差的中位数为 92–118 像素。种子 1 在 1000 步时 AUC@5 还有 0.214（测试集 0.192），仍低于未训练时；到 2000 步跌到 0.015，之后配准误差的中位数为 101–113 像素。两个种子的熵都降到 1 左右（相当于约 3 个位置），最高分位置的概率为 0.63–0.69。

*随机评分同样把概率压到一个位置上，配准失效。* 随机评分和抽到什么无关，平均下来不偏向任何抽签。但种子 0 的熵从 5.5（相当于约 240 个位置）降到 2000 步时的 0.002，最高分位置的概率接近 1；种子 1 塌得更早，1000 步时熵已只有 0.04。两个种子在 1000 步以后的验证集 AUC@5 都不超过 0.012，配准误差的中位数为 148–309 像素。

**讨论**

引言提出的两个问题，本文回答了第一个：在这套设置下，两种不用标注的评分都没有让配准超过未训练的模型，只有灰度相关评分在 4000 步时回到未训练时的水平。第二个问题没有得到回答。随机评分本是用来确认“模型的变化来自评分”的对照，预期它让模型基本不动，实际上它也把概率压到了一个位置上。因此，从这批结果里分不出评分的作用和其他因素的作用。

本文有三点局限。第一，只用了一个温度（1）、一个学习率（3e-5，LoRA 为 1e-4）、每步一对图，训练 4000 步。第二，每种评分只有两个种子，而两个种子之间差别很大：吻合度评分在种子 1 上 1000 步时还正常，在种子 0 上已经失效。第三，对已经失效的训练，按验证集挑出的存档只是失效最轻的那一个，它的测试集数字不代表这种评分的能力。

以下现象本文没有解释，也没有检验：

- 随机评分和抽到什么无关，为什么也会在 1000–2000 步内把概率压到一个位置上。
- 灰度相关评分在 1000 步附近的下跌和之后的回升与什么有关。回升和学习率变小发生在同一时段，但本文没有改变学习率去检验两者的关系。
- 吻合度评分为什么评分上升、配准却失效，以及两个种子失效的时间为什么相差很大。
- 照原概率抽签得到的结果，按真值算是否普遍比不抽签差。此前的检查只比较了抽签和不抽签两份输出之间的差别，本文也没有用真值检查。
