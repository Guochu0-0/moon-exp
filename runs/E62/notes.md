# 种子 0 下，两级都采样 16 次时 Test AUC@5 最低

**摘要**

在 Moon-v2 上从同一份 AnyMatch RoMa 公开权重出发，分别组合粗级和细级各 8 或 16 次采样。四组都跑完 8,000 步，各用同一批 980 对无标注 Val 图像选权重。种子 0 下，仅一级增加采样时，Test AUC@5 的变化不到 0.06 个百分点。两级都采样 16 次时，Test AUC@5 为 30.19%，比其余三组低 1.11–1.20 个百分点。四组训练用时相差最多 2 分 25 秒。

**引言**

RoMa 先估计粗匹配，再在五个尺度逐级细化。E55 的完整方法在粗级从预测分布采样，在细化的每一级从当前匹配位置附近独立采样，并以位置奖励更新模型。粗级和细级的采样次数可以分别设置。本实验在 Moon-v2 上交叉比较两级各采样 8 或 16 次，观察配准精度与训练耗时，并检查一级的变化是否随另一级而变。

**方法**

*训练。* 四组在 Moon-v2 的 6,909 对 Train 图像上从公开初始化权重重新训练。配置沿用 E55 的 `k5_no_bce`，保留粗级位置奖励、五级细化位置奖励及逐级独立的局部采样、EMA 参照 0.996、DINOv2 LoRA 秩 8、样本筛选门槛 0.8，以及两路零 BCE 权重。各组统一种子 0，在 160 的四张 V100 上以有效 batch 4 训练 8,000 个计划步。每 250 步存档一次，训练用时按成功运行的启动记录起止计算，包含训练初始化、样本筛选和存档。

*选权重与评测。* 每组将 32 份存档各自在同一份 980 对无标注 Val 清单上跑匹配。逐对内点率为 3 px RANSAC 内点数除以匹配点数，零匹配记 0。对覆盖完整且无执行错误的候选取逐对等权均值，均值最高者入选，同分取较早一步。每组仅对入选权重跑一次正式 Test。合并 Test 有 1,955 对图像，其中 1,605 对有人工检查点并纳入统一仿射评测。每对误差是预测仿射映射后与人工检查点的平均像素距离。AUC 是指定阈值内的归一化误差累积曲线面积，SR 是误差不超过该阈值的图对比例。

**结果**

*四组都完成了 32 份完整的 Val 评测和一次正式 Test。* 所有候选覆盖相同的 980 对 Val，正式 Test 均覆盖全部 1,605 对带标注图像。表 1 的精度指标和 Val 内点率均以百分比计。

*增加一级采样时，Test AUC@5 的变化随另一级的取值而变。* 固定细级为 8 次时，粗级从 8 增到 16，AUC@5 增加 0.051 个百分点。固定细级为 16 次时，同一改动使 AUC@5 降低 1.109 个百分点。固定粗级为 8 次和 16 次时，细级从 8 增到 16 分别降低 0.035 和 1.196 个百分点。两种固定条件下的变化之差为 −1.160 个百分点。表 2 列出其他指标和训练用时在同样对照下的变化。

*四组都训练了约 3 小时 20 分钟。* 各组实际完成 7,991–7,994 次参数更新，其余计划步因混合精度溢出跳过更新。四次成功运行都达到 8,000 步，均未触发提前停训。`c16_f16` 的第一次启动因共享 GPU 上出现外部进程撤下，未生成存档，随后从同一公开权重重跑。表 1 的用时取重跑的成功记录。 [训练启动记录](launch/)

**讨论**

种子 0 下，粗级和细级同时采样 16 次的配置在 AUC@3、AUC@5 和 AUC@10 上均为四组最低。固定另一级为 8 次时，增加采样对 AUC@5 的读数影响很小。四组训练用时的最大差距为 145 秒，其中 `c8_f8` 运行期间曾短暂观察到同卡的外部进程。这些运行时间反映整次训练的实测耗时。

本实验只测种子 0。为使评测与训练并行，`c8_f8` 在 154 的 TITAN RTX 评测，其余三组在 V100 评测。所有组使用相同的匹配和评分配置。尤其接近的读数应结合单种子和评测硬件差异理解。Moon-v2 合并 Test 含历史开发阶段使用过的旧 Val。 [完整方法配方 #285](https://github.com/Guochu0-0/moon-exp/issues/285) · [Moon-v2 协议 #305](https://github.com/Guochu0-0/moon-exp/issues/305)
