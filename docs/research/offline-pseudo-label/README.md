# 离线伪标签与迭代自训练：别的领域怎么做，哪些能用到 S1（#52）

> 问题：S1 只是一轮最简单的离线伪标签（zero-shot 打标 → 仿射 RANSAC 3 px 筛 → LoFTR 原始损失训练）。第二轮重新打标（S1r2）停在 0.267–0.271，没有提升。别的领域怎么做离线伪标签和迭代自训练？哪些能用到 AnyMatch-LoFTR + 仿射几何上？
>
> 标注约定：**【原文】** = 从论文正文（arXiv PDF 经 pdftotext，或 LaTeX 源）读到的，给出节号或表号；**【推断】** = 本文的判断，没有实验验证。出处和读了哪些部分见 [sources.md](sources.md)。
> 调研日期：2026-09-28。
> 不重复已有调研，需要时只引用结论：`research/online-selfsup-collapse`（S2 在线伪标签为什么塌、RIPE++ 为什么不塌、负样本对与位置编码捷径）、`docs/research/label-free-reward/`（各类无标注信号，以及「自洽信号看不见系统偏移」）、`docs/research/matcher-rl-feasibility/`（LoFTR 系的监督与微调门槛）。

## 结论速览

1. **S1r2 不涨，文献里有现成的解释：老师和学生「耦合」。** 【原文】ST++ 指出，学生和老师结构相同、初始化相近时，会犯同样的对和错，学生「除了熵最小化学不到额外信息」（ST++ §3.3）。Curriculum Labeling 的实验里，固定高阈值的伪标签「第一轮之后几乎不再提升」（CL 表 6）。【推断】S1 的损失本质上是「让匹配和它们自己的 RANSAC 仿射一致」。第一轮的增益来自 RANSAC 在很多匹配上做了平均，所以伪仿射比单个匹配准（SCENES 附录也这么说）。S1 训完后，它的匹配已经和自己的仿射一致，再用 S1 打标，目标就是它已经满足的东西，于是停在不动点。仓库事实：S1r2 是「用 S1 重新打标后**续训**」（`worktree-s1-recipe-50:runs/R/notes.md:51`），即学生从老师权重接着训，耦合最强。
2. **文献里让多轮自训练继续涨的，都是往学生那边注入老师没有的东西：** ①学生输入加强扰动，老师看干净输入（Noisy Student、ST++、DAFormer，以及事件–图像匹配 2607.10082 的单应增强）；②学生每轮重新初始化，不在老师权重上续训（Curriculum Labeling、Noisy Student Finding #8）；③换一个结构或初始化不同的模型做老师或互相筛（Co-teaching、DivideMix、ProDA 蒸馏到自监督初始化）；④逐轮扩大伪标签集合，而不是每轮用同一个固定阈值（CBST、CL、ST++、EYOC）。**S1 四样都没有**：没有增强，续训，同一个模型，固定阈值。
3. **筛选：文献普遍发现「分类置信度 ≠ 定位精度」。** 【原文】Soft Teacher 发现前景分数和框的定位精度相关性弱，改用「抖动后重回归的方差」来筛回归目标（§3.3，N_jitter = 10，方差阈值 0.02）。Unbiased Teacher 干脆不对框回归用伪标签（§3.2）。事件–图像匹配里，用老师自己的描述子相似度做置信度会让性能**下降**，作者称之为「循环依赖」（§4.4）。【推断】S1 用的「匹配 ≥ 100、内点 ≥ 20」相当于分类置信度，它说明仿射「大概对」，不说明仿射在 3 px 以内对。细级 l2 目标的可靠性应当另用稳定性来衡量。
4. **防塌缩最常见的做法，是把在线更新锚在一个固定的东西上。** 【原文】ProDA 的实验：在线用当前预测更新伪标签会「先涨后大幅下降」；把初始软标签 p_t,0 固定，只用原型距离对它重新加权，就能稳定上涨（ProDA 图 4 和 §5.3）。2403.12702 冻结基础模型，只训线性 adapter，再加重建损失。DAFormer 用 EMA α = 0.999，理由是「缓解伪标签漂移」。【推断】这和 S2 在线塌缩、S1 离线不塌的对比一致。但对粗对齐数据，锚点 A0 本身就接近恒等，锚定只能防漂移，挡不住位置捷径（见 `online-selfsup-collapse`）。
5. **没有任何一篇的自训练能纠正「一致的系统偏差」。** 【原文】SCENES 自己承认 bootstrap「会固化预训练模型学到的偏差」（§5 Limitations）；2403.12702 说自适应的上限受冻结模型本身性能的限制（§6.2）。【推断】S1 已知的「逐对、沿 x 的系统偏移」和「35% 对的仿射地板」不会被本文任何一条候选单独解决。能碰到它的只有带**外部信息**的做法：另一个结构的模型做老师或验证（C6），或者有精确真值的合成数据（C9）。前者能不能纠正，取决于两个模型的偏差是否同向。
6. **2403.12702 本身**：它的「EM」其实是**每个 iteration 在线重估**（E-step 用当前 adapter 取 argmax，共 60 次迭代），不是离线多轮。它能不塌，靠的是冻结的 DINOv2 特征、线性 adapter、InfoNCE 自带的负样本，加上重建损失（§3.4–3.6、§4.2、表 6）。其中能迁移到我们这里的只有两点：「冻结主体」和「锚回原表示」。它的检索式 EM 需要一个离散的候选集合，没法直接对应到仿射配准上【推断】。
7. **最值得先试（详见第 6 节）：** ①Noisy-Student 式的第二轮：伪标签用 S1 在干净输入上打，学生**从 zero-shot 权重重新开始**，训练时对 SAR 施加**已知随机仿射加光度/散斑扰动**，标签按 T∘A 精确变换；②用 AnyMatch-RoMa（或 MINIMA-RoMa）离线打第二套仿射，做交叉验证或直接当老师；③用**稳定性**（多个 ckpt 或多次扰动下仿射的一致度）代替内点数来筛选和排序伪标签，按课程扩大集合。三条都只改训练端，推理不变慢。

## 0. S1 的现状（仓库事实，只列和本题有关的）

- 打标：zero-shot 在 Train 上推理一次 → 仿射 RANSAC 3 px → 去掉匹配 < 100 或内点 < 20 的对，剩 7880 对。粗级 sparse focal，正样本是光学格经伪仿射落到的 SAR 格；细级 l2_with_std。AdamW，lr 1e-5 恒定，bs 1，8000 步，全部参数都训，没有 warmup/衰减/裁剪，**不混原域数据**，**没有数据增强**（`finetune/data.py`，见 `online-selfsup-collapse` §0）。
- 结果：Val AUC@5 从 0.220 升到 0.272，前 1000 步就涨到位，之后在 0.260–0.272 之间波动。
- 在 S1 之上续训的变体（`worktree-s1-recipe-50:runs/R/notes.md:47-52`）：S1c（续训 4000 步）0.260–0.268；S1lr3（从 zero-shot 出发，lr 3e-5）最好 0.264；**S1r2（用 S1 重新打标后续训）0.267–0.271**；S3a（在线，只监督内点格）从 step 3000 起塌到 0.012。另外 #50 在做 warmup / cosine / 裁剪的优化配方，本文不涉及。
- 已知诊断（#23）：35% 的对任何仿射都过不了 3 px（SR@3 上限约 0.65）；存在逐对、沿 x 的系统偏移。

## 1. 起点：2403.12702 读到的内容（arXiv v1，LaTeX 源）

**任务**：跨视角地理定位，本质是检索。query（无人机或地面）与 reference（卫星）配对，训练集没有配对标签。【原文】

| 五件事 | 读到的 |
|---|---|
| (1) 伪标签怎么生成 | 单模型。E-step 用当前 adapter 输出的特征，对每个 query 取内积 **argmax** 的 reference 作为一热伪标签（式 (4)）。正文另有一句「assigned above a fixed threshold value, which is set at 0.1」，和 argmax 式子怎么配合，原文没说清（§3.4）。【原文】 |
| (2) 怎么筛选 | 除上面这个 0.1 阈值外**没有**筛选，也没有置信度加权。【原文】 |
| (3) 怎么迭代 | 算法 1：**每个 iteration** 随机抽 M 个 query，用当前 θ 做 E-step，再用 InfoNCE 做一步 M-step 更新。University-1652 上 T = 60 次迭代，每次用全部 701 张卫星图加 700 张随机无人机图；CVUSA/CVACT 上 T = 10，各抽 1.5k（§4.2）。没有单独的 teacher，也不从头训。所以它是**在线**伪标签，不是离线多轮。【原文】 |
| (4) 怎么防确认偏差和塌缩 | ①冻结基础模型 DINOv2，特征预先离线提取；②adapter 只是一个线性投影（1536 → 2048，2.25 M 参数）；③AIC 模块（§3.5）：反向线性映射加 L2 重建损失，让适配后的特征能重建原特征，权重和 L_EM 一样都是 1；④InfoNCE 自带负样本。消融（表 6）：只用 EMPL，R@1 63.93；加 residual 连接反而降到 55.44；加 AIC 升到 69.45。作者解释：不加 AIC，特征会「过度相似」，判别力下降（§4.6「Analysis of the AIC Module」，图 13）。【原文】 |
| (5) 训练哪些参数 | 只训 adapter（加 reverter），基础模型冻结。有个对照值得注意：**用真标签**训同一个 adapter，R@1 只有 59.61，低于无标签 EMPL 的 63.93。作者的解释是有监督的 adapter「收敛快但过拟合训练数据」（§4.5，表 6）。【原文】 |

**局限**（§6）：自适应的上限「与冻结模型的性能内在相关」。在 Ground-to-satellite 上，冻结模型本身 R@1 < 0.1%，这套方法就推不动。【原文】

**对我们的含义**【推断】：
- 它的「EM」对应的是我们的 S2（在线重估），不是 S1。它在线不塌，是因为 InfoNCE 的负样本直接惩罚「全都配到一起」，再加上冻结主体和重建锚定。S2 的粗级 focal 只监督正样本格，没有负样本项；这一点和 `online-selfsup-collapse` 的结论（加负样本对）一致。
- 「冻结主体，只训小模块」在它那里可行，一个原因是检索只需要全局向量在一个线性子空间里重排。LoFTR 的瓶颈在 3 px 以内的定位，需要改动的是粗级 transformer 和细级窗口，线性 adapter 的容量不一定够。
- 可以直接借的是**锚回原表示**：对 zero-shot 的特征做重建或距离正则（候选 C8）。

## 3. 横向看：什么让多轮自训练继续涨，什么让它停住

**会继续涨的条件**【原文，逐条对应表中行号】：
- **学生看到的比老师难**：Noisy Student（#11，去噪声就降）、ST++（#13，打破耦合）、DAFormer（#9）、事件–图像（#5，学生看单应增强后的输入，标签用已知 H 精确变换）。
- **学生不从老师权重续训**：Curriculum Labeling（#12，每轮重初始化，最终 5.41 vs 6.42）、ST++（#13）、ProDA（#8，蒸馏到另一个初始化）、Noisy Student Finding #8。反例：SGP（#3）中续训和从头训差不多，EYOC（#4）中小数据集上续训更稳。**重初始化不是普遍必要的**，但当学生和老师太像时有用。
- **集合逐轮扩大**：CBST（#6）20% → 50%；CL（#12）20% → 100%；ST++（#13）先 50% 再全部；EYOC（#4）按难度扩展；SGP（#3）被接受的比例逐轮升到 90%+。反例：CL 表 6 中固定高阈值「第一轮之后几乎不再提升」。
- **老师的误差和学生不同源**：Co-teaching / DivideMix（#17、#18）用两个网络；事件–图像（#5）用外部极线几何，而不用自己的描述子相似度。

**会停住或塌的条件**：
- 在线更新而没有锚点（ProDA 图 4 的动态标签曲线；我们的 S2 / S3a）。
- 老师不鲁棒（SGP 的非鲁棒 teacher 失败）。
- 课程太快或过滤太严，导致正样本太少（EYOC：去掉渐进数据集就失败；阈值过严就发散）。

**对照 S1r2**【推断】：S1r2 是「同一模型、续训、无增强、同一套固定筛选规则」，正好落在「会停住」的所有条件上。另外，S1 的 Val AUC@5（0.272）本质上就是「S1 自己打的伪仿射在 Val 上的质量」，而 S1r2 学生停在 0.267–0.271，也就是**学生 ≈ 老师**，和 ST++ 描述的耦合现象一致。第一轮能超过老师（0.220 → 0.272），是因为 RANSAC 的聚合让伪仿射比单个匹配准；这个一次性的增益用完之后，同一套配方就没有新信息可学了。

## 5. 候选做法清单

「适用」一列：**可用** = 直接对应到 AnyMatch-LoFTR + 仿射上，不用改结构；**部分** = 要改造，或只能解决一部分问题；**不适用** = 前提不成立。推理代价：除特别注明外，全部只改训练端，推理不变。

| 编号 | 做法 | 来源（表中行号） | 适用 | 针对 S1 的什么问题 | 说明 |
|---|---|---|---|---|---|
| C1 | 每轮从 **zero-shot 权重**重新开始，而不是在 S1 上续训 | #12、#13、#11 | 可用 | 第二轮不涨（耦合） | 【推断】文献里的「重初始化」多是随机或自监督初始化；我们只有 AnyMatch 权重，退回 zero-shot 是最接近的版本。单独用预期作用有限（SGP 中两者差不多），应和 C2 一起用。成本为 0 |
| C2 | **学生加强扰动，老师看干净输入**：对 SAR 施加已知随机仿射 T（平移 ≥ 1–2 个粗格，加小旋转和缩放），标签按 T∘A 精确变换；再加光度、散斑、模糊扰动 | #11、#13、#9、#5 | 可用 | 第二轮不涨；平台期 | 【推断】S1 目前**完全没有增强**。仿射标签在已知 T 下可以精确合成（这正是事件–图像 #5 的做法）。附带好处：学生无法靠「按位置配」的捷径拿到目标（目标随 T 移动），这也是 `online-selfsup-collapse` 第 8 节第 4 步所需。**不能**纠正系统偏移（`label-free-reward` §2.D：变换一致性对平移偏差没有信号），这里的 T 只用来变换标签，不是用来提供监督信号 |
| C3 | 按**稳定性**筛选和加权：同一对在多个 ckpt（zero-shot、S1 的若干步）或多种输入扰动下的仿射离散度；离散度小的才进入细级 l2，或按离散度加权 | #13、#14、#3 | 可用 | 平台期（标签噪声）；为 C4 提供排序依据 | 【推断】「内点 ≥ 20」对应 Soft Teacher 说的「分类分数」，不反映 3 px 以内的精度。**可以先零成本验证**：在 Val（有真值）上看离散度和真实重投影误差的相关性，相关才用。成本是离线多跑几次推理 |
| C4 | **课程式扩大**伪标签集合：按 C3 的稳定性（或内点率）排序，第 1 轮取前 x%，每轮放宽，每轮用上一轮模型重打标 | #6、#12、#13、#4 | 可用 | 第二轮不涨（集合不变） | 【推断】目前两轮用的是同一套固定筛选规则，一轮 7880 对基本都进。CBST 从 20% 起、每轮 +5%，CL 每轮 +20%，ST++ 50% → 100%，可作为起点。要和 C1/C2 一起用，否则学生仍然耦合 |

## 6. 最值得先试的三条，和理由

**第一：C2 + C1 + C4，做成一个 Noisy-Student 式的「第二轮」。** 【推断】
- 做法：伪标签用 S1 在干净输入上打（这批标签在 Val 上的质量对应 0.272，好于 zero-shot 的 0.220），也可以用 C4 的课程只取前 x%。学生**从 zero-shot 权重出发**，训练时对 SAR 施加已知随机仿射 T 加光度 / 散斑扰动，标签按 T∘A 变换。
- 理由：S1r2 同时违反了文献里多轮能涨的三个条件（学生不比老师难、续训、集合不变），而这三条的改动都只在 `finetune/data.py` 和训练入口，推理不变。唯一要写的新代码是按 T 精确变换仿射标签，这一点仿射下是闭式的。
- 判据：Val AUC@5 明显超过 0.272，才说明「耦合」是 S1r2 不涨的主因。如果不超过，说明瓶颈在伪标签本身的质量（第 4 节第 1 行），应转向 C6 / C9。

**第二：C6，AnyMatch-RoMa 打第二套伪标签，先在 Val 上看偏移方向。** 【推断】
- 做法：离线在 Val 上跑 RoMa 系模型，逐对比较它和 LoFTR 相对真值的 x 偏移是否同向（零训练成本）；再在 Train 上用 A_L 和 A_R 的一致性筛选，或者直接让 RoMa 当老师。
- 理由：这是清单中唯一引入**外部**信息的做法。前面所有的自训练做法都看不见系统偏移（结论第 5 条），也不会改变 35% 的地板。它的前提（两个模型偏差不同向）可以先零成本检验，检验结果本身就回答了「偏移是模态本身造成的，还是 LoFTR 特有的」。

**第三：C3，用稳定性代替内点数筛选 / 加权细级目标，先在 Val 上验相关性。** 【推断】
- 做法：对每对，在 zero-shot 和 S1 的几个 ckpt（或几种输入扰动）下各估一次仿射，算离散度；在 Val 上看离散度和真实误差的相关性。相关的话，用它筛掉细级目标不可靠的对，并作为 C4 课程的排序依据。
- 理由：Soft Teacher 和 Unbiased Teacher 都明确发现分类置信度不代表定位精度，而我们的瓶颈恰好是 3 px 以内的定位。验证成本只是离线推理，不用训练；它也直接决定第一条里课程怎么排。

三条都不需要改网络结构，不影响推理速度。第一条和第三条可以合并成一组实验。
