本实验是类 RIPE 路线的两轮训练实验，以粗级 ±1 期望为基础，逐项加入其他训练信号。实验分五部分：第一轮在基础上逐项加细级信号、改外点扣分、加数据扰动；按误差阈值拆开看只训粗级时小误差段的变化；第二轮扫描外点扣分，并把细级强化学习限制在细级模块；用检查点拆分剩余误差并估计评测上限；只用不需要标注的量选模。

## 第一轮：在粗级期望之上逐项加信号

**实验目的**

类 RIPE 路线原定的建模是粗级和细级都加训练信号。上一个实验确认，只用粗级 ±1 期望从 zero-shot 起点训练不会塌缩，并能提高精度，但开始的 10–100 步会先掉到没有匹配。本轮以粗级期望为基础，逐项加入原定的三种细级信号，看它们能否在粗级之上继续提高；同时试两种避免开头掉到没有匹配的办法：学习率 warmup，以及把外点的扣分从 −1 减小到 −0.25。伪标签路线同期发现，给学生的输入加已知的随机扰动是关键，所以又补了扰动这一项。

**实验方法**

基础配方：起点是 AnyMatch 发布的 LoFTR 多模态权重；损失为粗级 ±1 期望（做法同上一个实验），外加负样本对；训练全部模块，网络保持推理模式。优化器为 AdamW，学习率前 500 步从 1e-6 线性升到 1e-5，之后按余弦曲线降到 0，batch 1，共 4000 步。在第 250、500、750、1000 步和之后每 500 步保存权重并在 Val 上评测，取 Val AUC@5 最高的一步作为结果，只在这一步上评测 Test。

每个方法只在基础配方上改一项：

- 细级闭式期望：细级把本步 RANSAC 仿射给出的位置当作目标，按细级输出到目标的平方距离训练。它相当于以「到目标的负平方距离」为 reward、在细级输出上加高斯噪声的策略梯度，期望可以直接写出来，不需要采样。
- 细级逐匹配强化学习：在每个细级输出上加高斯噪声，采样 4 次，按到 RANSAC 仿射的残差分档给 reward，用策略梯度训练。
- 细级整对强化学习：整对匹配共享同一个随机平移，采样 4 次，reward 是平移后两幅图梯度幅值的归一化互相关（NCC）。这是三种信号中唯一能看到整体偏移的一种。另有一个方法把这一项的权重从 1 降到 0.25。
- 外点扣分 −0.25：粗级期望中外点记 −0.25，而不是 −1。
- 已知随机扰动：给 SAR 加随机仿射（平移 ±12 px、旋转 ±3°、缩放 ±3%）和光度扰动作为数据增强，打分仍以本步匹配的 RANSAC 仿射为参考。另有一个方法用更强的扰动（±24 px、±5°），一个方法把扰动和外点扣分 −0.25 一起用。

两种细级强化学习各配一个随机 reward 对照：逐匹配的 reward 在匹配之间随机打乱，整对的 reward 换成随机数；粗级期望保留真实的分数，所以对照只隔离细级这一项。基础配方、外点扣分 −0.25、已知随机扰动及其与外点扣分的组合都另用随机种子 1 跑了一次。

同一配方换种子时，Val 峰值的差别可达 0.01，Test 的差别可达 0.02，所以比较时看第 2000 步及以后 5 个存档的 Val AUC@5 均值。开跑前定的判定标准是：比上一个实验加负样本对的方法（Val 峰值 0.285）高 0.01 以上，并且高于对应的随机对照，才算这一项有效。

**实验结果**

第 2000 步及以后的 Val AUC@5 均值 ± 标准差：

| 方法 | 种子 0 | 种子 1 |
|---|---|---|
| 上一个实验，加负样本对（学习率恒定，3000 步） | 0.268 ± 0.005 | |
| 基础配方 | 0.278 ± 0.002 | 0.277 ± 0.004 |
| + 细级闭式期望 | 0.266 ± 0.004 | |
| + 细级逐匹配强化学习 | 0.270 ± 0.007 | |
| + 细级整对强化学习 | 0.271 ± 0.004 | |
| + 细级整对强化学习，权重 0.25 | 0.274 ± 0.003 | |
| 外点扣分 −0.25 | 0.287 ± 0.002 | 0.287 ± 0.002 |
| + 已知随机扰动 | 0.280 ± 0.005 | 0.283 ± 0.003 |
| + 强随机扰动 | 0.232 ± 0.025 | |
| 外点扣分 −0.25 + 已知随机扰动 | 0.284 ± 0.004 | 0.291 ± 0.002 |

两个随机 reward 对照在 500–750 步内掉到没有匹配，Val AUC@5 降为 0。

warmup 消除了开头掉到没有匹配的现象：基础配方第 250 步的 Val AUC@5 已有 0.260，上一个实验同一步是 0.225，更早时几乎为 0。外点扣分 −0.25 起得更快，第 250 步就有 0.282。

外点扣分 −0.25 向恒等变换的漂移最大：负样本对上的恒等匹配数从起点的 3 个升到约 60 个，正样本对上恒等匹配的置信度从 0.001 升到 0.019；估出的仿射离恒等变换仍约 25 px，4000 步内 AUC 没有下降。加已知随机扰动后，恒等匹配回到 0–3 个，置信度约 0.001；与外点扣分 −0.25 一起用时为 5–15 个、0.004–0.007。

**实验结论**

本轮最好的形式只用粗级：粗级 ±1 期望、外点扣分 −0.25、负样本对加 warmup。两个种子第 2000 步以后的 Val 均值都是 0.287，Test 为 0.266 和 0.268，比基础配方高约 0.009，没有达到开跑前定的 0.01，但两个种子一致。

三种细级信号都比不加差，Val 均值低 0.004–0.012。随机对照能把粗匹配整个拖垮，真实 reward 把它拉住了，说明 reward 里有信号，但净效果仍为负：细级项的梯度经过共享的特征网络，伤到了粗匹配。

已知随机扰动不提高精度，但能压住向恒等的漂移；扰动过强有害。

## 只训粗级时小误差段的变化

**实验目的**

第一轮最好的方法只训了粗级损失，细级没有直接的监督。由此产生一个问题：只训粗级，3 px 以内的小误差段是不是提不上去。本部分按误差阈值把第一轮的结果拆开看。

**实验方法**

在 Val 上比较各阈值的成功率和 AUC@3。对比对象包括伪标签路线第一轮最好的方法（训了细级），以及用检查点最小二乘拟合仿射得到的上限（每对用全部检查点拟合，再在同样的点上评测）。

**实验结果**

| Val | AUC@3 | SR@2 | SR@3 | SR@5 | SR@10 |
|---|---|---|---|---|---|
| zero-shot 起点 | 0.059 | 0.051 | 0.293 | 0.584 | 0.853 |
| 基础配方 | 0.090 | 0.110 | 0.377 | 0.719 | 0.952 |
| 外点扣分 −0.25 | 0.092 | 0.110 | 0.379 | 0.768 | 0.960 |
| 三种细级信号 | 0.084 / 0.088 / 0.089 | 0.090 / 0.107 / 0.103 | 0.354 / 0.359 / 0.373 | 0.704 / 0.742 / 0.707 | 0.940 / 0.951 / 0.931 |
| 伪标签路线最好的方法 | 0.090 | 0.104 | 0.393 | 0.747 | 0.957 |
| 检查点最小二乘 | 0.205 | 0.304 | 0.650 | 0.926 | 0.997 |

三种细级信号依次为闭式期望、逐匹配强化学习、整对强化学习。

从起点到基础配方，小阈值也提高了：SR@2 从 0.051 到 0.110，SR@3 从 0.293 到 0.377。从基础配方到外点扣分 −0.25，增益全在 SR@5 和 SR@10，SR@3 和 AUC@3 不变。相对于检查点最小二乘，SR@10 已达到 96%，SR@5 为 83%，SR@3 为 58%，AUC@3 为 45%，SR@2 为 36%。

**实验结论**

只训粗级也能提高小误差段：特征网络是共享的，粗级信号改善了特征，匹配更多、更干净，RANSAC 估出的仿射就更准。每对的误差是几千个匹配拟合出的仿射的误差，而不是单个匹配的精度。

但小误差段在基础配方之后就不再上涨。本轮加的细级信号没有抬高它，训了细级的伪标签路线也停在同一处。这些细级目标都来自模型自己的 RANSAC 仿射，只会把匹配拉向模型当前的仿射，看不到逐对的整体偏移；唯一能看到整体偏移的整对 NCC 信号在训练全部模块时净效果为负。小误差段要继续提高，细级信号需要带进模型自己没有的信息，并且不能拖坏粗匹配。

检查点最小二乘的上限偏乐观（见「误差拆分与评测上限」），离它的差距不全是算法的余地。

## 第二轮：外点扣分扫描与只训细级的整对强化学习

**实验目的**

第一轮确定以外点扣分 −0.25 为本路线的基础，但外点扣分只试了两个值。细级整对强化学习在训练全部模块时伤到了粗匹配；此前在离线伪标签模型上只训细级模块时，它比随机对照高约 0.015。本轮扫描外点扣分，并把细级整对强化学习限制在细级模块，看能否在新的基础上得到增益；另补一个种子。

**实验方法**

配方与第一轮相同（学习率 1e-5，warmup 500 步加余弦衰减，4000 步），基础为外点扣分 −0.25。各方法：

- 外点扣分 0、−0.1、−0.5。扣分为 0 时只奖励内点，需要留意是否更快地漂向恒等变换。
- 一次训练、只进细级模块：在基础上加细级整对强化学习（共享平移，采样 4 次，reward 为梯度幅值 NCC），这一项的梯度只更新细级模块。
- 两段训练：从外点扣分 −0.25 的第 1500 步出发，冻结粗级，只训细级模块，只用细级整对强化学习；学习率 5e-5，每 16 对累积一次梯度，4000 步。
- 后两种各配一个随机 reward 对照；外点扣分 −0.25 另用随机种子 2 跑一次。

判定标准同第一轮：比外点扣分 −0.25 高 0.01 以上，并高于对应的随机对照；细级因素另看 AUC@3 和 SR@3。

开跑前先在 CPU 上做了一项检查：把外点扣分 −0.25 的 Val 预测在测试时平移到梯度 NCC 的峰值，看整体偏移修正还有多少增益。

**实验结果**

测试时平移到 NCC 峰值后，Val AUC@5 从 0.292 降到 0.288，只有 47% 的对变好；同样的操作在离线伪标签模型上是从 0.272 升到 0.284。NCC 峰值离真值的中位距离为 1.32 px，只有 33% 在 1 px 以内。

Val AUC@5 均值 ± 标准差（一次训练的方法取第 2000 步及以后，两段训练取第 1000 步及以后）：

| 方法 | 均值 ± 标准差 |
|---|---|
| 外点扣分 0 | 0.282 ± 0.002 |
| 外点扣分 −0.1 | 0.285 ± 0.001 |
| 外点扣分 −0.25（三个种子） | 0.287 / 0.287 / 0.287 |
| 外点扣分 −0.5 | 0.284 ± 0.002 |
| 外点扣分 −1（第一轮的基础配方） | 0.278 ± 0.002 |
| 一次训练，细级整对强化学习只进细级模块 | 0.285 ± 0.002 |
| 同上，随机 reward 对照 | 0.275 ± 0.003 |
| 两段训练，细级整对强化学习 | 0.290 ± 0.002 |
| 同上，随机 reward 对照 | 0.292 ± 0.002 |

外点扣分为 0、−0.25、−0.5 时，负样本对上的恒等匹配约为 65、61、35 个，置信度为 0.022、0.019、0.009，4000 步内都没有塌缩。外点扣分 −0.25 三个种子的 Test AUC@5 为 0.266、0.268、0.267。

**实验结论**

外点扣分在 −0.1 到 −0.5 之间差别很小，−0.25 最好；扣分越大，向恒等的漂移越小。本路线的方法定为外点扣分 −0.25，三个种子的结果一致。

细级整对强化学习只进细级模块时，比随机对照高 0.010，说明 reward 有信号，但仍低于不加它的方法，增益只够抵消策略噪声本身的伤害。两段训练与它的随机对照相当，两者略高于基础，是因为从峰值出发并冻结了粗级，而不是 reward 的作用。测试时平移到 NCC 峰值已经不涨，说明 NCC 能修正的整体偏移，基础模型已经学到了。本轮没有一项达到判定标准。

## 误差拆分与评测上限

**实验目的**

两条路线都停在 Val AUC@5 0.29 左右，需要知道剩下的误差来自仿射的哪一部分，以及按现有评测协议，一个完美的逐 patch 仿射估计能拿多少分。此前用检查点最小二乘估计的上限（SR@3 约 0.65）是在拟合用的同一批点上评测的，可能偏乐观。

**实验方法**

误差拆分：把外点扣分 −0.25 的预测仿射分成平移和线性部分（旋转、缩放、剪切），分别换成由检查点得到的最优值，看指标升到多少。另外计算两个参照：把检查点拟合的仿射平移到梯度 NCC 峰值（图像内容意义下的最优）；留一法，即用其余检查点拟合仿射、在留出的点上评测。

评测上限：检查点带有每轴约 1 px 的标注误差，x 方向另有仿射表达不了的错位。把错位建模为平稳的高斯过程，相关长度按观测到的残差拟合（约 100–130 px），幅度逐对估计，标注误差取独立同分布的高斯（每轴 1 px），用蒙特卡洛模拟出整片最优仿射在本协议下的分数。另算三个参照：世界若恰好是仿射、只有标注噪声；错位在检查点之间互不相关；检查点最小二乘。

**实验结果**

误差拆分（Val）：

| | AUC@3 | AUC@5 | SR@3 | 中位误差（px） |
|---|---|---|---|---|
| zero-shot 起点 | 0.059 | 0.219 | 0.293 | 4.22 |
| 外点扣分 −0.25 | 0.092 | 0.292 | 0.379 | 3.50 |
| 平移换成最优 | 0.119 | 0.328 | 0.439 | 3.21 |
| 线性部分换成真值 | 0.135 | 0.349 | 0.472 | 3.11 |
| 检查点仿射平移到 NCC 峰值 | 0.139 | 0.378 | 0.525 | 2.94 |
| 检查点最小二乘，同点评测 | 0.205 | 0.453 | 0.650 | 2.55 |
| 检查点最小二乘，留一法 | 0.049 | 0.209 | 0.232 | 4.27 |

伪标签路线最好的方法拆分结果相同：AUC@5 0.291，平移换成最优 0.328，线性部分换成真值 0.353。

评测上限（AUC@3 / AUC@5 / AUC@10，SR@3）：

| 估计 | Val | Test |
|---|---|---|
| 只有标注噪声，世界恰好是仿射 | 0.582 / 0.749 / 0.875，1.00 | 同左 |
| 检查点最小二乘，同点评测 | 0.173 / 0.429 / 0.703，0.61 | 0.195 / 0.428 / 0.703，0.60 |
| 整片最优仿射，错位按高斯过程 | 0.159 / 0.383 / 0.664，0.53 | 0.169 / 0.371 / 0.647，0.51 |
| 错位在检查点之间互不相关 | 0.050 / 0.282 / 0.625，0.29 | 0.055 / 0.275 / 0.621，0.30 |
| 外点扣分 −0.25（参照） | 0.092 / 0.292 / 0.594，0.38 | 0.091 / 0.266 / 0.559，0.35 |

相关长度取 16–512 px 时，高斯过程估计的 AUC@5 在 0.365–0.385 之间；标注误差取每轴 0.8–1.2 px 时，上限变化约 ±0.01。全部检查点拟合仿射后，每个自由度的残差平方在 x 方向为 19.8 px²，y 方向为 1.7 px²（中位数 11.8 和 1.3）；y 方向与每轴 1 px 的标注误差相符，x 方向的多出部分不是少数离群的对造成的。

**实验结论**

剩下的误差平移和线性部分都有，线性部分略大。

限制上限的是 x 方向的非仿射错位。仿射方法的 AUC@5 上限约为 0.37–0.38，两条路线最好的方法在 Val 上达到上限的约 76%，在 Test 上约 72%，还有 0.09–0.10 的空间；AUC@3 的上限只有约 0.16，现在为 0.09。检查点最小二乘同点评测的「SR@3 上限 0.65」偏乐观，留一法偏悲观，两者都不宜作为上限。上限的估计依赖两条假设：标注误差独立同分布、错位是平稳的高斯过程。

## 只用不需要标注的量选模

**实验目的**

本工作的训练不用标注，但选模仍用了 Val 上的标注。如果只用不需要标注的量也能选出差不多的模型，「不用标注」这一点会更完整。

**实验方法**

只用 Val 影像上的匹配和 RANSAC 结果计算三个量：每对内点数的中位数、内点数不少于 200 的对所占比例、内点比例的中位数。在 35 个训练（粗级期望单独训练的两个方法、两条路线第一轮的全部训练、第二轮的部分训练，包括塌缩的两个随机对照）上，比较两件事：在同一个训练内用它选存档，相对 Val 峰值损失多少 AUC@5；在不同训练之间，它与 Val 峰值的秩相关。

**实验结果**

| 选模用的量 | 同一训练内选存档：平均 / 最大损失 | 不同训练之间的秩相关 | 按它选出的训练 |
|---|---|---|---|
| 内点数中位数 | 0.002 / 0.011 | 0.75 | 外点扣分 −0.25，种子 1 |
| 内点数 ≥ 200 的对的比例 | 0.002 / 0.011 | 0.87 | 外点扣分 −0.25 + 已知随机扰动 |
| 内点比例中位数 | 0.024 / 0.220 | −0.55 | 细级整对强化学习的随机对照（已塌缩） |

**实验结论**

内点数类的量可以代替 Val 标注选模：同一训练内的损失与换种子的波动同量级，而按 Val 峰值选本身就偏高。内点比例不能用，因为匹配塌缩到很少时，内点比例反而高。不同训练之间的秩相关被塌缩的训练拉高了，只看正常训练时的区分能力还没有单独计算。
